## A-1. VBA の実出力との突合が済んでいない

- **現場の紙（入力と、そのとき VBA が出した明細表）とは、まだ突き合わせていない。**

**要確認**: 同じロット・同じ積み順で VBA と移植版の紙を並べ、表題・副番の並び・重量・右上の文字が同じかを見る。

## A-2. 縦割数・横割数が整数でないとき

**場所**: `meisai/import_specs.py` `to_whole`（VER 0.13.19）。

- 以前は `int(float())` で切り捨てていた（2.7 → 2）。
- VBA の読み方（`Long` へ入れると 2.7 → 3）が分からないうえ、どちらにしても前工程実績数・丈数が変わる。
- いまは **整数でなければ 0 で取り込み**、画面で前工程実績数を入れてもらう。ログに「割数が整数ではないため 0 で取り込みます」と残す。

**要確認**: VBA で整数でない割数をどう読んでいたか。実データに整数でない割数が出るか。

## A-3. 実績の形式の `BOX設計_*` を当工程設計の割数として使う

**場所**: `meisai/import_specs.py` `RESULTS_SPEC`、`common/ls4_source.py`、リポジトリ直下 `docs/仕掛ファイルの仕様.md` §3.2（VER 0.13.28・現場の指示）。

- LS4LOT の欄の名前が `LS4LOT` 以外なら実績の形式で読み、`BOX設計_縦割数 = 当工程設計_縦割数`、`BOX設計_横割数 = 当工程設計_横割数` として使う。

**要確認**: 同じロットについて、実績の形式の `BOX設計_*` と LS4LOT の `当工程設計_*` を突き合わせる。
食い違えば、前工程実績数と丈数（＝条番号・副番）が変わる。

## B-1. 復元後、出力していないのに「使用済み」で押せないコイルが残る（VBA のまま）

**場所**: `strand_service.Board.restored_used` の注記、`session._restore`。

VBA の `RestoreSnapshot` はギミックB の `IsUsed` を立て直すが、積み上げスロット（ギミックC）は作り直さない。

- 「灰色だがスロットには無い」コイルが残り、押しても反応しない。
- 次の `txtTsumiJouSu_Change` で `ResetGimmickBUsed` が回っても、スロットが空なので戻らない。
- 解除されるのは条番号の再表示のときだけ（確認「出力していない使用済みはリセットされます」が出る）。

途中経過を書くのは条番号表示・廃棄の増減・出力の 3 つの時点で、書く「使用済み」はそのときの
積み上げのコイルと、それまでに出力したコイル（`Board.committed_used`）。
そのため、ここに残るのは主に「出力したコイル」と「廃棄を付け外ししたときに積み上げに入っていたコイル」。
後者は出力していなくても、開き直すと押せない。
VER 0.13.26 から、開き直したときは紙に載っているコイル（明細出力）からも使用済みに戻している。

**要確認**: VBA のまま残してよいか。出力済み修正（VER 0.13.23）が入ったいま、困る場面が残っていないか。

## B-2. ロットを切り替えると前のロットの記録が消える（VBA のまま）

**場所**: `session.close_lot`（`DeleteLotSheets → ClearFubanList → ResetSeq → DeleteSnapshot`）、`routes/meisai.open_lot`。

違うロットを開くと、前のロットの次のものを消す。

| 消えるもの | 結果 |
|---|---|
| 出力済み（明細出力） | 前のロットの紙を画面から刷り直せない（明細の履歴からは作り直せる。VER 0.10.0） |
| 副番履歴（全件） | 前のロットに戻っても、出した副番の重複警告が出ない |
| 連番 | 前のロットに戻ると No1 から |
| 前のロットの途中経過 | 前のロットに戻っても、使用済み・廃棄が戻らない |

途中経過は「直近 5 ロット」まで持つ作り（`config.SNAPSHOT_KEEP`）だが、
ロットを切り替えるたびに前のロットの分を消すので、**実際に残るのはいま開いているロットの分だけ**になる
（切り替えでなく、アプリを開き直して同じロットを入れたときに復元される）。VBA も同じ順で消していた。

**要確認**: 現場で、一度離れたロットへ戻って続きを出すことがあるか。あるなら、出力済み・副番が消えることで
同じコイルの紙を 2 枚出す余地がある（明細の履歴の「副番」で探せば、出したかは分かる）。
