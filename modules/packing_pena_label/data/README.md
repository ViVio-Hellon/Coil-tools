# data フォルダ

アプリが読み込む初期マスタ・同梱サンプルを置く。

| ファイル | 用途 | 本番での扱い |
|---|---|---|
| `size_master.json` | サイズ構成マスタ（VBA `GetSizeConfig` の外出し） | **土台。** 新しいサイズは設定の「サイズ」から足す(共有の資材マスタの表「ペナラベル追加サイズ」に入る。統合 1.2.16)。ここを直すのは同梱のサイズを変えるときだけ |
| `型番.csv` | 型番マスタ（VBA の `型番` シート相当） | そのまま使用 |
| `資材重量.csv` | 試験用のサンプル値。「手本を出す」の中身 | **アプリは読まない**(統合 1.2.31)。本番は SQLite / Access、または設定で指定した CSV |

## 資材重量.csv について

**この CSV の単位質量・係数は検証用のサンプル値であり、実際の業務値ではない。**

本番では `config/app.json` の `aimRefPath`（VBA の `PATH_AIM_参照` に相当）配下の
`梱包資材マスタ.accdb` / テーブル `資材重量` を
`cscript.exe` + VBScript + ADODB + ACE OLEDB 経由で読む。

**アプリはこのファイルを読まない(統合 1.2.31)。** 以前は SQLite / Access に届かないとこの CSV に落ち、
画面右上の札が「CSV（検証用）」に変わるだけで、サンプルの単重で NW/GW を計算したラベルが刷れた。
いまは、届かなければ前に読んだ内容で続け(「古い内容」)、一度も読めていなければ計算を止めて理由を出す。
業務で CSV を使うときは、設定「資材マスタ CSV」に業務値の CSV を指定する(「手本を出す」でこのファイルの形を写せる。
**値は必ず業務値に直すこと**)。試験・通し試験は、このファイルの写しを指定した CSV として読ませる
(`tests/_material.py`・環境変数 `PPL_MATERIAL_CSV`)。

列名は Access のフィールド名と一致させること（`管理番号` / `梱包資材名` / `単位質量` / `係数`）。
資材名は VBA がハードコードしていたものと完全一致が必要（`ф` はキリル文字）。


---

## 本番マスタを置かないこと

**受領した実マスタ（`梱包資材マスタ.sqlite3` / `.accdb`）は、このリポジトリに含めない。**

理由: 実マスタには本システムが使わないテーブルも入っており、
`班員名簿`（氏名）・`アクセス権限`（ログインID・PC名）・
`コイル包装仕様マスタ`（取引先名・納入先名）など、
**個人情報や取引先情報が含まれる**。

本システムが読むのは `資材重量` テーブルの
`梱包資材名` / `単位質量` / `係数` だけで、他のテーブルには一切アクセスしない。

実マスタは **共有フォルダーに置き、設定（`material_db_file` または
`aim_ref_path`）からパスで参照する**。`.gitignore` で `*.sqlite3` を除外済み。
