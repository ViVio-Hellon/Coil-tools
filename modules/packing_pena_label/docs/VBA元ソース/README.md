# ペナラベルの VBA 元ソース

2026-10-22 に現場から受け取った、移植元の Excel VBA のソースです(統合 1.2.33 の時点で受領)。
**移植の根拠を確かめるための資料**で、ツールが読むものではありません。

## 経緯(現場の担当より)

もとの VBA は **ハードコード(コードの中に値を直接書いたもの)が多かった**。それを少しずつ外へ出したり
変数(定数)にしたりして整理し、そのうえで現在の Python への移行に踏み切った。
`New_Calculation.bas` の定数(`CHIP_THICKNESS_MM`・`PALLET_HEIGHT_MM`・`HB_THICKNESS_MM` など)や
`テスラ補助.bas` の座標の定数(`COL_COIL_L` など)は、その整理の途中の形です。Python 側はこの流れを
引き継ぎ、サイズ構成を `data/size_master.json` へ、資材の単重を資材マスタへ、印刷位置の補正を設定へ外に出しています。

| フォルダ | 中身 |
|---|---|
| `元のまま/` | 受け取ったまま(Shift_JIS)。Excel の VBE へ「ファイルのインポート」で戻せる。`.frx` はフォームの部品の既定値などが入ったバイナリ |
| `読む用_UTF-8/` | 同じ中身を UTF-8 に直し、改行を LF にした写し(GitHub・エディタで読む用)。中身は変えていない |

| ファイル | 中身 |
|---|---|
| `テスラ指定サイズ.frm` / `.frx` | フォーム「テスラ指定サイズ」(指定サイズの画面。サイズ選択・重量反映・重量計算_DB・印刷・クリア など) |
| `GW用.bas` | 計算・ラベル転記・羅列計算・クリア・印刷設定・資材マスタ(梱包資材マスタ.accdb)の読み込み |
| `New_Calculation.bas` | 定数(チップボール厚・パレット高さ・HB 厚 など)・新しい計算(GetCoilTA など)・ログ・風袋罫線設定 |
| `テスラ補助.bas` | 台紙の座標・ラベルの書き方・全サイズの台紙(シート追加・コピー・型番入力・印刷範囲1/2・印刷実行) |
| `テスラ全サイズ.frm` / `.frx` | フォーム「テスラ全サイズ」(全サイズの画面。サイズ選択・2ケタ/3ケタ・決定・印刷) |

- 受け取っていないもの: `UserForm4`・`表記用`・`警告`・`UFProgress`、定数 `PATH_AIM_参照` の定義(別の共通モジュール)
- 移植との突き合わせの結果は、`docs/01_VBA解析書.md`・`docs/03_不明点と要確認事項.md` と変更履歴に書く
