# 仕掛ファイルの仕様と列の関係

対象の版: コイル梱包ツール 1.2.30(梱包明細 VER 0.13.28 / 資材計算 0.2.28)

梱包明細と資材計算が読む「仕掛」の sqlite3 ファイルの、置き場所・ファイル名・列の使い方をまとめたものです。
どのファイルも、**このPCの一時フォルダへ写してから読みます**(共有の上では開きません。`common/source_copy.py`)。

---

## 1. 置き場所(第1パス・第2パス)

| | フォルダ | ファイル | 名前を変えられるか | 設定の鍵 |
|---|---|---|---|---|
| 第1パス | 仕掛台帳 | SIKALOT / SIKAHIKI / SIKAODR | 変えられない | `lot_db_dir` |
| 第1パス | 梱包課共有の仕掛(上とは別のフォルダ) | LS4LOT | **変えられる** | `konpo_db_dir`・`konpo_db_file` |
| 第2パス | 4ファイル共通の1つのフォルダ | 上の4つの代わり | **4つとも変えられる** | `lot_db_dir_2`・`lot_db2_file_lot` / `_hiki` / `_odr` / `_ls4` |

- 第1パスに無いファイルは、第2パスの名前で読みます。
- 第1パスに無いロット(受注)は、第2パスから足します。両方にあれば第1パスを使います。
- 第2パスの名前が空なら、第1パスと同じ名前で探します。
- 第1パスと同じファイル(同じフォルダ・同じ名前)は2度読みません。
- 拡張子を省いた名前は `.sqlite3` → `.db` の順で探します。拡張子まで書けば、その名前そのものを探します。

| 機能 | 読むファイル |
|---|---|
| 梱包明細 | SIKALOT・SIKAHIKI・SIKAODR・LS4LOT(または実績の形式) |
| 資材計算 | SIKAHIKI・SIKAODR。実績の形式のファイル(LS4LOT の名前を変えたとき)だけ、コイル外径のために読む |

---

## 2. LS4LOT は名前で形式が変わる

**LS4LOT の欄に入れたファイル名で、読み方(形式)が決まります。** 決まりは `common/ls4_source.py` の1か所で、
梱包明細と資材計算が同じものを使います。

| ファイル名 | 形式 |
|---|---|
| `LS4LOT`(`LS4LOT.sqlite3`・`ls4lot.db` など。大文字小文字は見ない) | いままでの形式(梱包課共有の仕掛) |
| それ以外の名前(例: `実績_LS4.sqlite3`) | 実績の形式 |

`実績_LS4.sqlite3` はあくまで例です。LS4LOT 以外の名前なら、何でも実績の形式として読みます。

### なぜ2つの形式があるのか

LS4LOT は**作られる時刻が大事なファイル**で、梱包の作業と作られる時刻が合わないことがあります
(作業しているロットがまだ載っていない など)。そのときの受け皿として、実績の形式のファイルを使えるようにしています。

例えば、第1パスを LS4LOT のまま、第2パスの「LS4LOT の代わり」に実績の形式のファイル名を入れます。
すると、LS4LOT に無いロットだけが実績から足されます。逆の組み合わせ(第1パスが実績、第2パスが LS4LOT)もできます。

## 3. 列の関係

### 3.1 いままでの形式(名前が LS4LOT)

| 元の列 | 手元の表「仕掛当工程」の列 | 使いみち |
|---|---|---|
| `ﾛｯﾄ番号` | ロット番号 | 鍵 |
| `当工程設計_縦割数` | 当工程設計_縦割数 | 丈数の初期値・前工程実績数 |
| `当工程設計_横割数` | 当工程設計_横割数 | 前工程実績数 |
| `当工程設計_設備名`・`当工程設計_枚本数`・`製造板厚`・`製造板幅`・`製造板丈` | 同じ名前 | 写すだけ(いまは使っていない) |

行は絞りません(ファイルにある行を全部取り込みます)。

### 3.2 実績の形式(名前が LS4LOT 以外)

| 元の列 | 対応 | 使いみち |
|---|---|---|
| `ﾛｯﾄ番号` | ロット番号 | 鍵 |
| `BOX設計_縦割数` | **= 当工程設計_縦割数** | 梱包明細: 丈数の初期値・前工程実績数 |
| `BOX設計_横割数` | **= 当工程設計_横割数** | 梱包明細: 前工程実績数 |
| `BOX実績_作業開始_日付` | 行の絞り込み | **いまの年月の行だけ**使う |
| `BOX実績_ｺｲﾙ内径` | コイル外径の計算 | 資材計算: 外径 = 内径 + 2 × 肉厚 |
| `BOX実績_ｺｲﾙ肉厚` | コイル外径の計算 | 同上 |
| `BOX実績_枚本数` | 検入数(本) | 資材計算: 検入数の既定値。無ければ `BOX設計_横割数 × BOX設計_縦割数`(同じ数のはず) |

**行の絞り込み(BOX実績_作業開始_日付)**

- `2026-10-21 00:01:56` のような値の、**年と月(`2026-10`)だけ**を見ます。今日の年月と同じ行だけを使います。
- `2026/10/21` のような `/` 区切りも読みます。年月が読めない行は使いません。
- 同じロットが何行もあれば、作業開始がいちばん新しい行を使います。
- 今月の行が1つも無ければ、手元の表は空になります(先月の割数は使いません)。

**列が足りないとき**

- 実績の形式なのに `ﾛｯﾄ番号`・`BOX設計_縦割数`・`BOX設計_横割数`・`BOX実績_作業開始_日付` のどれかが無ければ、取り込みません。
  取り込みの結果に、足りない列を出します。
- ファイルの中で表の名前は問いません。要る列をそろえた表を探して読みます(`仕掛` という表があれば、それを先に見ます)。
- 内径・肉厚・枚本数は無くても取り込めます。無ければコイル外径・検入数を出さないだけです。

## 4. 資材計算のコイル外径・検入数

受注を選んだとき、コイル外径の欄に入れる値は次の順で決めます(`coil_tool/lot_service.load_into`)。

1. **実績の形式のファイルにそのロットがあり、内径・肉厚がどちらも 0 より大きい** → 外径 = 内径 + 2 × 肉厚(小数2桁)。
   画面に「コイル外径は実績から出しました」と出します。
2. それ以外 → いままでどおり、受注の `ｺｲﾙ外径_MAX`。

外径の欄は、どちらの場合も打ち直せます。

**検入数(本)**(統合 1.2.30)も、受注を選んだときに次の順で入れます。**先に手で入れてあれば上書きしません。**

1. 実績の形式のファイルにそのロットの `BOX実績_枚本数` があれば、その数。
2. 無ければ `BOX設計_横割数 × BOX設計_縦割数`(同じ数のはず)。画面に「検入数は実績から入れました」と出します。
3. どちらも無ければ、いままでどおり空(手で入れる)。

- 資材計算は、LS4LOT の名前が `LS4LOT` のままならこのファイルを読みません(内径・肉厚が無いため)。
- 第1パス(梱包課共有のフォルダ・名前)と第2パス(仕掛台帳の第2パスのフォルダ・「LS4LOT の代わり」の名前)の順に読み、
  第1パスに無いロットだけを第2パスから足します。
- 取り込んだ値は、資材計算の作業用DBの表「コイル実績」(ロット番号・内径・肉厚・外径・枚本数・作業開始・元ファイル)に入ります。
- 取り込むのは、起動時の自動取り込み(元が変わったときだけ)と「いま取り込む」のときです。
