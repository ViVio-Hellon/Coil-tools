# 変更履歴(統合アプリ)

## 版の決まり

版は**統合ツールの版と3機能の版を分けて**持ちます(`common/versions.py`)。混ぜません。

| 種類 | 出どころ | いつ上げるか | 変更履歴 |
|---|---|---|---|
| 統合ツールの版 | `config/app.json` の `version` | **配るたび。** 統合画面・共通部分・起動/停止/配布を変えたとき、または機能の版が1つでも上がったとき | このファイル |
| 梱包明細の版 | `modules/packing_details/config/app.json` | 梱包明細の中身(画面・計算・印刷・DB)を変えたとき | `modules/packing_details/docs/変更履歴.md` |
| ペナラベルの版 | `modules/packing_pena_label/app/config.py` の `APP_VERSION` | ペナラベルの中身を変えたとき | `modules/packing_pena_label/docs/変更履歴.md` |
| 資材計算の版 | `modules/packing_material_calculation/config/app.json` | 資材計算の中身を変えたとき | `modules/packing_material_calculation/docs/変更履歴.md` |
| 移植元の版 | 各機能の `__init__.py` の `PORTED_FROM` | 変えない(取り込んだときの記録) | ― |

- 機能の番号の付け方は、その機能のまま(移植元と同じ「メジャー.マイナー.パッチ」)
- 画面の帯の版(`VER1.0.0`)を押すと、統合ツールと3機能の版・移植元が並んで出ます。
  タブにもそれぞれの機能の版が出ます
- **起動時の入れ替え判定は、統合ツールの版と3機能の版の組で比べます。** 機能の版だけを
  上げて配っても、古いプロセスに合流せずに入れ替わります
- CSS・JS の URL には「版-中身の指紋」が入るので、版を上げ忘れても古いものは使われません
- 配布メモ(`配布メモ.txt`)・起動時のログ・`/api/health` にも、4つの版が分けて出ます

### 1.0.0

- 初版。梱包明細 (VER 0.13.1)・ペナラベル (v1.5.0)・資材計算 (VER 0.2.0) を
  1つの Flask サーバ・1つの画面(タブ)に統合した。中身は `docs/統合設計.md`
- (初版を配る前に直したもの)自動終了の見張りを**画面ごとに数える**ようにした。
  別タブの印刷ページも心拍を送るので(下の「印刷」)、統合画面のタブを閉じても
  開いている間は終わらない(ペナラベルの移植元の「使っている間は止まらない」を守る)
- (同)資材計算の心拍で、「裏に回った」合図が「閉じた」合図を取り消していたのを直した
  (統合画面を閉じても終わらないことがあった。梱包明細の決まりに揃えた)
- (同)ペナラベルの配布設定の置き場所を、梱包明細・資材計算と同じ `配布設定\<機能>\`
  にした。配布用フォルダを作る処理が3機能ぶんをまとめて入れ、「入れない」を選べば
  どれも入れないようにした(以前は梱包明細・資材計算の分が入らず、ペナラベルの分は
  選ばなくても入っていた)。書き出したときの案内も実際の置き場所を示すようにした
- (同)**印刷**: 3機能とも印刷は別のタブで開く(梱包明細の帳票・ペナラベルの印刷ビュー・
  資材計算のチェックリストと発注票)。統合アプリがこれらの画面に小さな心拍のスクリプト
  (`static/js/tab_alive.js`)を差し込み、**開いているあいだはサーバを止めない**ようにした。
  帳票は紙面で書き足した値をサーバへ保存し、発注票はサーバが覚えている中身から組むため。
  各機能のコードと紙面の中身は変えていない。ペナラベルだけに足していた心拍はこれに一本化した
- (同)**Ctrl+P** は、いま見せている機能の画面を刷るようにした(ブラウザの Ctrl+P は一番外の
  文書を刷るので、そのままでは統合画面の見出しとタブと、画面の見えている部分だけが紙に出た)
- (同)ブラウザが取りに来るアイコン(`/favicon.ico`)に根で答えるようにした(ペナラベルの
  移植元と同じ。印刷ビューを開くたびに 404 が出ていた)
- (同)**版を分けた**: 画面の帯に版の一覧、`/api/health` に `versions` と `version_set`、
  起動時の入れ替え判定を版の組で、静的ファイルの URL に中身の指紋、配布メモと起動ログに
  4つの版。3機能の変更履歴に「統合版への組み込み」を書いた(機能の版は移植元のまま)
