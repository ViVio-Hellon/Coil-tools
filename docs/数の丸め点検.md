# 数の丸め・切り捨ての点検(統合 1.2.6・1.2.12 で再点検)

python-web-tools(梱包資材総合ツール)で、**取り込み・書き込みのときに数を勝手に丸め・切り捨て、
VBA と違う数を DB に書いていた**不具合が見つかりました(VER4.8.3: 注文の丈 2502.5 → 2502、
枚本数 2.9 → 2 など。原因は取り込みの `int()`)。同じ種類がコイル梱包ツールの3機能に無いかを洗いました。

- 調べ方: 取り込み(取り込み元 → 手元 DB)・画面からの入力・計算・保存(手元 DB・共有 DB・Access)・印刷の
  すべての数の変換(`int()`・`round()`・書式・切り捨て・SQL の型・JS の `parseInt` / 入力の制限)を読み、
  VBA(各機能の VBA 解析書・VBA の書き出し・移植のコメント)と比べた
- **3機能とも、問題はすべて統合の前(移植元のリポジトリ)からあったもの**です。統合で増えたものはありません
- 取り込みの経路: 梱包明細・資材計算の取り込み元は sqlite(以前の Access から置き換え済み)。ペナラベルは
  Access(cscript → VBScript → ADODB → ACE)も読みます。VBScript は値を `CStr` で文字にして渡すので、
  そこで小数は落ちません

## 現場に確かめたこと(10/10)

- **積数は小数点第1位で切り捨て。** 1不可の Re_積数 3.5 → 3 は今のまま(切り捨て)で正しい。**ただし、リプラの本数は割ったままの値(2.5 など)で数える**(統合 1.2.32。切り捨てた値で数えると、分けた2台のコイル間リプラが 2本少なかった)。割り切れる計算が
  2進の誤差で 1 少なくなっていたのは直した(上の表)
- **ラベルに刷る重量は VBA の台紙と同じ小数1桁が正。** 重量器は小数2桁まで量れないので、打つ値はふつう小数1桁まで

## 再点検(1.2.12): 丸め方と丸める時点

計算のある3機能で、**すべての数を入力 → 途中 → 画面・保存・印刷まで追い**、VBA の丸め方(`Format`・`Round`・
`RoundUp/RoundDown`・`CInt/CLng`・`Val`・`Int/Fix`)と**丸める時点**(途中で丸めるか・最後に丸めるか・
丸めた値を足すか、足してから丸めるか)を照らし合わせた。境目の数(x.xx5・.5・割り切れる割り算)で試した。

- **丸める時点の違いは見つからなかった**(3機能とも)。風袋の合計は丸める前の各項目を足し、NW だけ先に丸めて
  GW に足す(VBA と同じ)。梱包明細の重量は整数のまま紙・履歴まで行く
- 資材計算の VBA の書き出し(22行)は、直したあとも全部一致

### 決められないもの(VBA の元のコードが手元に無い)

- **資材計算の `台数計算` の引数の型**(厚み・幅・単重が Single か Double か)。Single なら 1760 ÷ 70.4 は VBA でも 24 に
  なる(今のツールは Excel と同じ 15 桁の見方で 25)。VBA の書き出しに割り切れるロットが無く、確かめられない。
  確かめるには `照合出力.bas` に疑似ロット(例: 包装仕様 1C1300・幅 21.6・単重 30・重量 1000・検入数 50)を足して、
  VBA の出力と照らす
- 資材計算の `Atu = 0.8` の比べ方(不明点 Q14)、単重再計算の π と型、外径の Single
- ペナラベルの風袋・GW の `Round`(VBA の Round なら偶数の側、Excel の ROUND なら 0 から遠い側)。π が入るので .5 ちょうどには
  ならず、実際には差が出ない
- 梱包明細の縦割数・横割数の VBA の読み方(Long へ入れるなら 2.7 → 3)。今のデータは整数だけ

### 意図して VBA と違うもの(以前の決定)

- ペナラベルの羅列の NW・GW: 旧 VBA は丸める前の NW で GW を出していたが、「羅列は風袋計算と同じ」(A-2/A-3)の決定で
  風袋計算と同じ順(NW を先に丸める・EX-DRY 込み)にしている

## 数の変わらない作り(確かめたもの)

- マスタ管理の書き込み(ペナラベル・資材計算): 打った値を `?` で渡す。2.5 は 2.5 のまま(sqlite の型で丸まらない)。
  資材計算は "940" を "940.0" と書く(数は同じ)
- ペナラベルの入力(重量・高さ・全サイズ): 打ったままの文字で保存
- 資材計算のチェックリスト・発注票・発注履歴: 計算した文字をそのまま保存(丸めるのは計算の側。上の表)
- 梱包明細の記録(明細出力・スナップショット・履歴): 整数の重量をそのまま。紙の `Kg` は小数1桁で出す
