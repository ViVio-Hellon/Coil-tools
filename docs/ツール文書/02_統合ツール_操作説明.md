# 統合ツール 操作説明

対象の版: コイル梱包ツール 1.2.29(梱包明細 VER 0.13.28 / ペナラベル 1.5.31 / 資材計算 0.2.27)

コイル梱包ツールの「入れ物」の使い方です。起動・終了・画面の見方など、3 つの機能に共通のことを説明します。
各機能の操作は、それぞれの操作説明(12・22・32)を見てください。
ツールの中の説明書(上の帯の「説明書」→「はじめに・統合画面」)と同じ中身を、文字だけで書いています。

---

## 1. 起動する

### 1.1 どれを押すか

| 押すもの | 開くところ | 使うとき |
|---|---|---|
| **コイル梱包ツール.exe**(デスクトップ版) | 専用の窓 | **ふだん。** ネットワークの「ポート」(通信の窓口の番号)を使わないので、ほかのソフトとぶつかりません |
| **Start.vbs**(ブラウザ版) | ブラウザのタブ | exe が無いとき・動かないときの予備 |
| start.bat | ブラウザのタブ + 黒い窓 | ブラウザ版が起動しないとき、理由を見るため(§6) |

- どれも、アプリ一式が入ったフォルダの中から押します(ファイルだけをデスクトップに写すと動きません。ショートカットは大丈夫です)
- ショートカットを作るときは、`scripts\make_shortcuts.vbs` をダブルクリックします。ツールのフォルダに
  「コイル梱包ツール(ブラウザ版)」と「コイル梱包ツール(デスクトップ版)」ができます(exe が無いフォルダではデスクトップ版は作りません)

### 1.2 デスクトップ版の手順

1. アプリのフォルダの **コイル梱包ツール.exe** をダブルクリックします。窓がすぐ出て「起動しています」と表示されます
2. 台帳の取り込みが終わるまで、待機画面に進み具合(実行環境 → 準備 → 取り込み → 完了)が出ます。
   急ぐときは **「待たずに使い始める ▸」** で先に入れます(取り込みは裏で続きます)
3. 統合画面が出たら使えます

### 1.3 ブラウザ版の手順

1. **Start.vbs** をダブルクリックします。黒い窓は出ません
2. ふだん使っているブラウザに待機画面が開き、そのあとは デスクトップ版の 2・3 と同じです

### 1.4 気をつけること

- **デスクトップ版とブラウザ版は同時には動きません**(同じデータを使うため)。片方が動いているときにもう片方を起動すると、
  理由が出て起動しません。動いているほうを終了してから起動してください
- 2 回起動しても、2 つ目は起動しません。デスクトップ版は開いている窓が前に出ます。ブラウザ版は動いているツールの画面がブラウザで開きます
- 統合前の単体版(3 つを別々に動かしていたころのもの)が動いていると起動しません。単体版を止めてから起動してください

## 2. 統合画面の見方

```
上の帯  コイル梱包ツール VER1.2.21   画面の色[自動|ライト|ダーク]  説明書  ログ  接続OK  [終了]
タブ    [梱包明細 VER0.13.21] [ペナラベル VER1.5.28] [資材計算 VER0.2.22]
中身    選んだツールの画面
```

| 部分 | 見方・使い方 |
|---|---|
| **タブ** | 押して切り替えます。キーボードの ← → でも移れます。名前の右の小さな文字が、そのツールの版です |
| **版**(VER1.2.21) | 統合ツールの版です。押すと 3 つのツールの版の一覧が出ます |
| **画面の色** | 自動・ライト・ダーク(§2.3) |
| **説明書** | いま見ているタブのツールの説明書が開きます(§2.4) |
| **ログ** | ログとエラーの記録を見ます(§2.5) |
| **接続OK** | アプリが動いている印です。「接続なし」や赤い帯が出たら §7 を見てください |
| **終了** | アプリを終わります(3 つのツールとも終わります。§3) |

### 2.1 ツールを切り替える

- タブを切り替えても、**入力の途中の値や結果は消えません**。途中で別のツールを使って、戻ってから続きができます
- 統合画面を 2 枚開くと、3 つのツールがそれぞれ「別の画面で開いています」になります。
  使いたい画面で、ツールごとに「この画面で使う」を押します

### 2.2 版を見る

版は**統合ツールの版**と**3 つのツールの版**を分けて持っています。問い合わせるときは、この版を伝えてください。

1. 上の帯の版(VER1.2.21)を押します
2. 統合ツールと 3 つのツールの版、移植元の版が並びます。もう一度押すか、ほかの場所を押すと閉じます

| どれの版 | いまの版 | 出ている場所 |
|---|---|---|
| コイル梱包ツール(統合ツール) | 1.2.21 | 上の帯の左・説明書のいちばん上 |
| 梱包明細 | 0.13.21 | タブ・梱包明細の見出し |
| ペナラベル | 1.5.28 | タブ・ペナラベルの左上と画面の下の帯 |
| 資材計算 | 0.2.22 | タブ・資材計算の見出し |

### 2.3 画面の色を変える

1. 上の帯の **自動 / ライト / ダーク** のどれかを押します。押すとすぐ変わり、このPCに覚えます
2. 統合画面・3 つのツールの画面・ログの画面がそろって変わります(読み直さないので、入力はそのままです)

- **自動** は Windows の「色」の設定(ライト/ダーク)に合わせます
- 紙(明細表・ラベル・印刷用の画面)は、どれを選んでも白地に黒のままです
- 「画面の色を保存できませんでした」と出たら、もう一度押してください(元の色に戻っています)

### 2.4 説明書を開く

1. 上の帯の **説明書** を押すと、いま見ているタブのツールの説明書(写真入り)が開きます
2. 説明書の上の「目次」「梱包明細」などで、ほかの説明書へ移れます
3. **別の窓で開く** で、別の窓(ブラウザ版では別のタブ)に開き直します。ツールの画面と並べて読めます
4. **閉じる** でツールの画面に戻ります

紙が要るときは説明書の「印刷する」で、開いている説明書だけを刷れます(ファイルの保存はしません)。

### 2.5 ログとエラーの記録を見る

上の帯の **ログ** を押すと、次の 3 つを見られます。**閉じる** で元の画面に戻ります。

| 面 | 中身 |
|---|---|
| エラーの記録 | 止まった処理の記録の一覧と中身(何が起きたか・どの操作のときか) |
| 今日のログ | 今日の記録。警告とエラーだけ/すべて |
| 出力先の設定 | ログの出力先と残す日数(既定 180 日)。「確かめる」「保存」「既定に戻す」 |

- ツールの画面に「エラー番号 E20261001-104512-3F9A」のような番号が出たら、**その番号を控えて伝えてください**
- 共有フォルダを出力先にすると、その下に PC の名前のフォルダを作って書きます。保存するとすぐ切り替わります
- ほかのPCにも同じ出力先を入れたいときは、同じ面の「配布設定(ほかのPCへ配る)」で書き出し、アプリのフォルダごと配ります。
  書き出す・読み込み直す・消すには**管理者パスワード(梱包明細と同じ)が要ります**

### 2.6 印刷する

- 各ツールの印刷ボタンで刷ります。帳票・印刷用の画面は、ブラウザ版は別のタブ、デスクトップ版は別の窓で開きます
- 統合画面で **Ctrl+P** を押すと、いま見せているツールの画面が刷られます
- ブラウザのメニューから印刷すると、見せている画面の 1 枚目の分しか出ません。印刷ボタンか Ctrl+P を使ってください
- 帳票の別のタブが開いているあいだは、統合画面を閉じてもアプリは止まりません(帳票で書き足した値の保存などが続けられます)

## 3. 終了する

1. 上の帯の **終了** を押します(デスクトップ版は、窓の右上の × でも同じです)。3 つのツールとも終わります
2. **まだ保存していない入力があるときだけ**、「まだ保存していない入力があります」と、どのツールのどの入力かが出ます。
   - **OK** … その入力は消えて終わります
   - **キャンセル** … そのまま使えます。入力のあるタブが出るので、保存してから、もう一度「終了」を押してください
3. 資材計算の取り込みなど、**途中の処理があるときだけ**「実行中の処理があります … 中断して終了しますか?」と出ます。
   **キャンセル** で待ち、終わってから押してください(**OK** だと中断して終わります)

どちらも無ければ、確認は出ずにそのまま終わります(業務ツール統合ランチャーから閉じたときも同じです)。
終わると、ブラウザ版は「終了しました。このタブは閉じてください。」と出ます。タブは手で閉じます。

**保存していない入力として出るもの(主なもの)**

| ツール | 出るもの |
|---|---|
| 梱包明細 | 7 桁になっていない LOT No・「確定する」を押していない前工程実績数・設定の保存していない欄 など |
| ペナラベル | 重量反映などのボタンを押していない新検番・重量・高さ、「決定」を押していない全サイズの入力 など |
| 資材計算 | チェックリストへ積んでいない計算・記録していない発注票 など(計算と発注票は止めると消えます) |
| ログ | 保存していない出力先・残す日数 |

資材計算の帯の「終了」も、上の帯の「終了」と同じ流れです。

### 3.1 ブラウザ版の自動終了

- ブラウザ版は、統合画面と帳票などのタブを**全部閉じると、少しあとで自動で終わります**
- 裏に回しても・PC がスリープしても・印刷の画面を開いたままでも、終わりません
- 作業の途中経過は各ツールが保存しているので、開き直せば続きから使えます
- 止まらないときは stop.bat を使います(§4)

## 4. stop.bat で止める(ブラウザ版)

1. アプリのフォルダの **stop.bat** をダブルクリックします
2. 開いている統合画面があれば、その画面に §3 と同じ確認が出ます。画面で答えてください
3. 止まると「[済] main: 正常に終了しました」のように出て、窓が閉じます

止められなかったときは、理由を出して止まります(何かキーを押すと閉じます)。

| 出る文 | 意味と、すること |
|---|---|
| 止めませんでした: 実行中の処理があります: … | 取り込みなどの最中です。終わってからもう一度。中断してよければ `stop.bat --force` |
| 止めませんでした: コイル梱包ツールの画面で「閉じない」が選ばれました… | 画面でキャンセルを選びました。入力を保存してから、もう一度 |
| 止めませんでした: まだ画面で確認中です。画面を見てください… | 画面に確認が出ています。答えれば自分で終わります |
| 終了要求に応じません(処理の途中かもしれません)… | 重い処理の途中で答えられないことがあります。少し待ってからもう一度。どうしても止めるときだけ `stop.bat --force`(1.2.26 から、`--force` が無ければ落としません) |
| デスクトップ版(コイル梱包ツール.exe の窓)が動いています… | stop.bat はデスクトップ版を止めません。窓が前に出るので、× か「終了」で閉じます |
| 強制終了を頼みましたが、まだ動いています | §7 の「まだ動いています」 |
| pid … はこのアプリではないようなので止めません | ほかのプログラムを巻き添えにしないため止めませんでした。タスクマネージャーで確かめてください |

`stop.bat --force` は、途中の処理も画面の確認も訊かずに止めます。中断してよいときだけ使ってください。

## 5. ランチャーから使う

業務ツール統合ランチャーには、今ある起動ファイルをそのまま登録します(1 台の PC にはどちらか 1 つ)。

| 起動ファイル | ランチャーのポート欄 | 止め方 |
|---|---|---|
| コイル梱包ツール.exe | **空にする** | 自動(窓の × と同じ) |
| Start.vbs | 8740(自動で入る) | 自動(stop.bat) |

start.bat は登録しないでください(ランチャーが画面を先に閉じるので、保存していない入力の確認を通りません)。
くわしくは `docs/ランチャー連携.md` を見てください。
Windows の実機で、ランチャーの本体から起動・切り替え・終了することは、まだ確かめていません(未確認。`docs/ランチャー連携.md` の「確かめきれていないこと」)。

## 6. start.bat で理由を見る

ブラウザ版が起動しないときに使います。黒い窓に経過と理由が出ます。

| 打ち方 | すること |
|---|---|
| `start.bat` | 環境を確かめてから、ふつうに開く。**この窓を閉じるとアプリも終わります** |
| `start.bat --check` | 環境の確認だけして終わる(Python・部品・書き込み・設定・ポート・プロキシの設定を表示) |
| `start.bat --diagnostic` | 細かいログまで残して開く(調べる人に頼まれたとき) |

ログは `%LOCALAPPDATA%\CoilPackingTools\logs` のいちばん新しいファイルです(上の帯の「ログ」で出力先を変えていればそちら)。

## 7. 困ったとき

| 出たもの・起きたこと | すること |
|---|---|
| 「Python が見つかりません(または起動できません)」 | デスクトップ版の窓に出ます。このPCに Python が入っていません。窓に出ている入れ方のとおりに入れてから、もう一度開いてください |
| 「Python が見つかりません。」(Start.vbs の窓) | Python を入れるとき「Add python.exe to PATH」にチェックを入れます。詳しくは start.bat で |
| 「pythonw が見つかりません。」 | start.bat から起動してください |
| 「start_app.py が見つかりません。」 | Start.vbs をアプリのフォルダの中から実行してください |
| 「ブラウザ版のコイル梱包ツールが動いています」 | ブラウザの画面で「終了」を押すか、stop.bat で止めてから、デスクトップ版を開き直します |
| 「デスクトップ版のコイル梱包ツールが動いています」 | デスクトップ版の「終了」を押してから、ブラウザ版を起動します |
| 「統合前の単体版が動いています: …」 | 単体版の画面を閉じるか、単体版のフォルダの stop.bat で止めてから起動します。単体版の Start.vbs やショートカットは消しておきます |
| 「使えるポートがありません(試した番号: …)」 | ほかのアプリがポートを使っています。そのアプリを終了するか、管理者に連絡してください |
| ブラウザに「起動できませんでした」の画面 | 出ている理由とログの場所を控え、start.bat で起動して黒い窓の理由を見ます |
| 赤い帯「バックエンドと通信できません。アプリを開き直してください。」 | アプリが止まっています。開き直してください |
| 赤い帯「アプリが開き直されています」 | 「読み込み直す」を押します |
| 「エラー番号 E…」 | 番号を控えて伝えてください。上の帯の「ログ」で中身を見られます |
| 待機画面に「起動できませんでした」「アプリを組み立てられませんでした: …」 | アプリのフォルダの一部が欠けている・設定が壊れているなどです。理由を控えて伝えてください。「このまま終了する」で終わります(画面を閉じても、しばらくすると自動で終わります。stop.bat でも止まります)。フォルダを入れ替えるのは、終わってからにしてください |
| 待機画面に「別のアプリが同じポートを使っています」 | ほかのアプリが同じ番号で答えています。管理者に連絡してください |
| 待機画面に「バックエンドに接続できません」 | 起動の途中で止まった可能性があります。開き直し、続くときは start.bat で理由を見ます |
| 「印刷の画面を出せませんでした」 | デスクトップ版の印刷用の窓に出ます。印刷の画面は同時に 1 つしか出せません。ほかの窓で印刷の画面が開いたままなら、そちらで刷るか閉じてから、もう一度「印刷する」を押します |
| stop.bat に「まだ動いています」 | 止めきれていません。タスクマネージャーで python を確かめてください。止まるまで、アプリのフォルダを消したり入れ替えたりしないでください |
| ブラウザ版が起動しない(何も出ない) | start.bat で起動すると、理由が黒い画面に出ます |
| タブを全部閉じたのに終わらない | 帳票のタブが残っていないか見ます。ブラウザが落ちたときなどは残ることがあります。次の Start.vbs はそのまま使えます。止めたいときは stop.bat |
