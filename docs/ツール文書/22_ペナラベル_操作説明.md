# ペナラベル 操作説明

対象の版: ペナラベル 1.5.53(コイル梱包ツール 1.2.59)

ペナラベルは、テスラ向けの出荷ラベル(小ラベル)を刷り、梱包の風袋(梱包資材の重さ)・NW(コイルの重さ)・GW(総重量)・高さを計算する機能です。
統合画面の **ペナラベル** タブで使います。現場向けの説明書(統合画面の「説明書」、`templates/manual/pena.html`)と同じ流れを、文章で詳しく書いています。

---

## 1. 画面の見方

ペナラベルを開くと「指定サイズ」の画面が出ます。

| 場所 | 見るもの |
|---|---|
| 左のタブ | 指定サイズ(ふだんの画面)・風袋計算・計算内容・ラベル台紙・設定(全サイズは 1.5.50 からいまは出していません) |
| 左上 | 版(v1.5.28)と、版を切った日 |
| 右上の札 | 資材マスタをどこから読んでいるか(SQLite・Access(ACE)・CSV)。赤い「（古い内容）」が付いたら、資材マスタを読み直せていません |
| 右上の接続 | 「接続OK」なら動いています |
| 下の帯 | 版・中身の指紋・「計算・印刷の記録」・「診断」 |

指定サイズの画面は、左から **コイルサイズ** → **現状値・1条重量** → **GW**(チップボール・積み本数・NW・GW・高さ) → **GW操作**(ボタン) の順に並んでいます。

---

## 2. 毎日の流れ(小ラベルを刷る)

全体の順番は次のとおりです。

```
サイズを選ぶ → 新検番・新重量を入れる → 重量反映
  → チップボール・積み本数を入れる → 重量計算_DB → 小ラベル印刷 → 印刷する
```

### 手順1 サイズを選ぶ

1. 丈1 と丈2 を **まとめて** やるときは、「まとめてやりたい場合チェックon（丈1・丈2 同時）」にチェックを入れます。片方だけなら外したままです。
2. サイズを選びます。
   - チェックを外しているとき: サイズごとの「丈1」か「丈2」
   - チェックを入れているとき: サイズごとの「丈1・丈2 同時」
3. 選ぶと、その台紙に前に書いた検番・重量が「現状値」に出ます。

- ふだん出ているサイズは 1.0mm×53.5mm と 0.8mm×53.5mm です(設定で増やせます。7 章)。
- サイズの下の赤字は注記です(例: 「New 2026.03.26追加」)。
- 選んでいない丈の重量の欄と積み本数の欄は薄くなり、入れられません。
- 1.0mm×53.5mm と 0.8mm×53.5mm の「丈1」「丈2」を選んだときは、その丈の積み本数・NW・GW・高さが空に戻ります(VBA と同じ動き)。
- チェックの入れ外しをすると、選んでいたサイズはいったん外れます。選び直してください。

### 手順2 新検番・新重量を入れて「重量反映」

0. ロット番号が分かるときは、先に **LOTNO** を入れて **検査番号を引く**(または Enter)を押します(1.5.52)。
   梱包明細と同じ取り込み元(検査番号は仕掛ロット SIKALOT など、外径は LS4LOT)でそのロットを探し、**検査番号が新検番に入り**、内径・肉厚から出した
   コイル外径でチップボールが選び直されます(チップボールの下に案内)。見つからないときは「LOTNO … が見つかりません(わけ)」、
   検査番号の列が無いときは「検査番号の列が見つかりません(列: …)」と出ます。そのときは新検番を手で入れます。
1. **新検番** を入れます。英字 1 文字 + 数字 1 文字 + 英数字 1 文字 + 数字 4 桁の 7 桁です(例 N6X0945・H670129。3 文字目は英字でも数字でもかまいません)。小文字は大文字に直ります。英数字以外は入りません。7 桁を超える入力(8 桁の貼り付けなど)は入らず、「検査番号は7桁までです」と出ます。数字の所に「E」などの英字があると重量反映で止まります(1.5.37)。
2. **新重量 丈1** を入れます(丈2 だけのときは不要)。
3. **新重量 丈2** を入れます(丈1 だけのときは不要)。丈1・丈2 同時なら両方要ります。
4. **重量反映** を押します。「重量を反映しました」と出て、「現状値」が新しい検番・重量になります。

このとき台紙(ラベル 32 枚ぶん)に、検番・重量・型番・コイル番号・バーコードの文字が書かれます。

### 手順3 チップボール・積み本数を入れて「重量計算_DB」

1. **チップボールサイズ**(1000 / 950 / 820)を選びます。LOTNO で引いたとき(手順2の 0)や、資材計算の仕掛パスが実績の形式のときは、**コイル外径(内径 + 2 × 肉厚)から近いものが選ばれ**、チップボールの下に「コイル外径 …mm → いちばん近いのは …。…を選びました。違うときは選び直してください」と案内が出ます(1.5.36)。違うときは選び直します。見つからないときは選ばずに理由が出ます。
2. **積み本数** を、丈ごとに 1梱包目・2梱包目 入れます(使わない梱包は空のまま)。本数は数字だけ打てます。
3. **重量計算_DB** を押します。資材マスタを確かめてから計算し、「計算しました」と出ます。時間がかかるときは進み具合の棒が出ます。
4. 梱包ごとに **NW・GW・高さ(mm)** が出ます。同じ値がラベルのヘッダー帯にも書かれます。

- 計算するのは**表示中の丈**の梱包だけです(隠れている丈の本数欄に値が残っていても計算しません)。
- 資材マスタに無い資材・単重が数でない資材があると「資材重量なし: …」と出て**計算を止めます**(どの資材か・読んだ資材マスタが出ます)。資材マスタを直してから押し直します。
- 止まったときは何も消えません(前の計算結果のまま)。
- 次のロット(違う検番)で重量反映すると、前のロットの NW・GW・高さと台紙の本数欄が消えます(刷ったあとは消えません。刷り直せます)。

> **重要** NW は「現状値」の重量(重量反映で台紙に書いた重量)で計算します。重量を変えたら、**先に重量反映**、それから重量計算_DB の順で押します。

> **注意** 重量・本数・検番・サイズ・チップボールを変えたら、必ずもう一度 **重量計算_DB** を押します。押さないまま刷ろうとすると「入力が変わっています。印刷を止めています。」と出て刷れません(古い値のラベルを出さないため)。風袋計算の印刷も同じです(1.5.30)。

### 手順4 「小ラベル印刷」で刷る

1. **小ラベル印刷** を押します。
2. 「○○ を印刷しますか？」が画面の中に出るので **OK** を押します。ラベルの紙面(実寸)が別のタブ(デスクトップ版では別の窓)で開きます。
3. 上の帯の **印刷する** を押します。印刷の窓は **何も変えずに** そのまま「印刷」で大丈夫です(倍率「実際のサイズ」・余白「なし」が最初から選ばれています)。
4. 刷り終えたら、上の帯の **このタブを閉じる** で閉じます。閉じられないときはブラウザの × で閉じます(ペナラベルのタブは開いたままです)。

- 1 台紙(1 つの丈)は、ラベル 16 枚 × A4 2 枚 = 32 枚です。丈1・丈2 同時なら A4 4 枚になります。
- 1 段目はヘッダー帯(サイズ名・検番・重量と、1梱包目・2梱包目の本数・高さ・NW・GW)です。
- 刷ったラベルが台紙の枠からずれるときは、5 章の位置合わせをします。

### そのほかのボタン

| ボタン | すること |
|---|---|
| 積み高さ計算 | 本数を聞いて、その本数を積んだときの高さ(チップボール・コイル・コイル高さ・梱包高さ。mm・小数 1 桁)を出します。風袋計算の高さと同じ式です。参考で、帳票には出ません。× で消すまで出ています |
| クリア | 確かめのあと、NW・GW・高さと全台紙の本数欄を消します |

## 3. 風袋計算を見る・刷る

### 3.1 風袋計算の画面

左のタブの **風袋計算** を押します。梱包ごとに表が出ます。

- 見出し: 「丈1_1梱包目:11本」のような名前と、巾・外径・外周・梱包高さ
- 表: ﾋﾟﾝ・ﾁｯﾌﾟﾎﾞｰﾙ・ｽﾄﾚｯﾁﾌｨﾙﾑ・ｴｻﾌｫｰﾑ・ﾎﾟﾘｼｰﾄ・ﾊｰﾄﾞﾎﾞｰﾄﾞ・樹脂ﾊﾟﾚｯﾄ・ﾍﾟｯﾄﾊﾞﾝﾄﾞ・EX-DRY・NW・風袋・GW の重さと、計算式
- マスタに無い資材・単重が数でない資材があると、計算は止まります(1.5.36。以前の版で計算した結果だけ、上に「0kg として計算しています」と出ることがあります)

刷るとき:

- **印刷ビューを開く** … 印刷用のタブが開き、すぐ印刷の窓が出ます(表だけ。図は出ません)。
- **このまま印刷** … いまの画面をそのまま刷ります。

### 3.2 「図で見る」の読み方

風袋計算の画面では、梱包ごとの表の下に、GW をどこから出しているかが図で出ます(「図で見る(GW をどこから出しているか)」。押すと閉じます)。図は計算をせず、表と同じ数を描いています。

**断面図(左)** … 梱包を横から見た模式図です。**左半分は外から見た所、右半分は断面(中の重なり)**です。包装仕様書(7C1175「包装仕様書」4. 荷姿の「内装」「前」「横」)に合わせて描いています(1.5.35 で描き直し)。

| 見るもの | 読み方 |
|---|---|
| 積み方(右半分) | 下から 樹脂パレット → 八角ハードボード(八角形緩衝材)→ チップボールとコイルを交互に → 一番上のチップボール → 八角ハードボード → 樹脂パレット(裏返し)。コイルの内径部に乾燥剤 |
| 外周を包む物(右の縁) | 内から ストレッチフィルム → ポリシート(上下も包む)→ エサフォーム(発泡ポリシート。1 周か 2 周)→ ハードボード |
| ピン(樹脂製丸棒) | 4 本。ハードボードの外に立て、下のパレットの穴に差します(フォーク爪の差し込み口より下に出さない・上のパレットより上に突き出さない) |
| PET バンド | 胴巻き 4 本(ハードボード用・丸棒用。下の方に 2 本・中ほどに 2 本。上の方はラベルを貼る所なので掛けない)と、上下のパレットを十文字に 2 本ずつ締める縦 4 本 |
| 高さ | 寸法どおりの縮尺です。ただしチップボール(0.7mm)とハードボード(2.35mm)は薄すぎて見えないので、太く描いています |
| 左の寸法 | 「コイル積高」(コイルとチップボールの高さ)と「梱包高さ」(10mm 単位で切り上げた値) |
| 上の式 | 「コイル積高 = 本数 × 巾 + チップボール 枚数 × 0.7mm」「梱包高さ = 積高 + 樹脂パレット 150×2 + 八角HB 2.35×2 = … → …mm(10mm 単位で切り上げ)」 |
| 右の札 | 資材ごとの色と重さ。線で描いた物と結んであります(エサフォームは 1 周か 2 周かも出ます) |
| 下 | 外径と外周 |

包む物の厚みと、丸棒・バンドの位置は目安です(重さの計算には使っていません。計算は表の式のとおり)。

**重さの内訳(右)**

| 見るもの | 読み方 |
|---|---|
| 一番上の帯 | GW = NW + 風袋。灰色が NW(コイル)、色の付いた所が風袋。丸める前の値と、表示の値(GW は整数に四捨五入)の両方が出ます |
| 風袋の内訳(9 項目) | 資材ごとの帯の長さで、どれが重いかが分かります。右に重さと割合、下に式(計算式の欄と同じ)が出ます |
| 一番下 | ハードボードの数え方(「固定物 HB590」「固定物 HB530」か「標準(外周+700mm × 積高)」)と、エサフォームが 1 周か 2 周か(積高 820mm を超えると 2 周) |

### 3.3 計算内容

左のタブの **計算内容** では、1 梱包ぶんの資材・重量・計算式と、資材マスタの一覧(梱包資材名・単位質量)が見られます。上に梱包ごとのボタン(例「丈1_1梱包目:11本」)が並び、押すとその梱包が出ます。最初は番号のいちばん小さい梱包(丈1 を計算していれば丈1 の梱包)です。戻るときは **指定サイズ** を押します。

## 4. ラベル台紙と全サイズ

### 4.1 ラベル台紙

左のタブの **ラベル台紙** で、台紙(サイズ × 丈)の一覧が見られます。

- 列: 台紙番号・シート名・型番・データ行・追加行・検査番号・重量・更新日時
- **表示** … ラベルの中身を一覧で確かめます(実寸ではありません)。上の「印刷ビューを開く」で実寸の紙面が開きます。
- **印刷** … 実寸の紙面が開きます。重量反映していない台紙には出ません。入力が変わったままのときは「印刷（停止中）」になります。
- 足したサイズには「追加」の印が付きます。
- 一番下の **新しいサイズを足すには** を押すと、足し方の手順と、このPCでいま足せるかが出ます。**設定の「サイズ」を開く** で 7.2 の画面へ移れます。

### 4.2 全サイズ

**いまは左のタブに出していません**(1.5.50。現場の指示: いまは使わない)。使うときは担当者が `config/app.json` の `show_all_size` を `true` にします。以下は出したときの使い方です。

左のタブの **全サイズ** で、型番マスタにあるサイズのラベルを作ります(風袋計算はしません)。

1. **サイズ選択(型番マスタ)** を選びます。台紙が用意され、画面が新しくなります。
2. **検番** を入れます(指定サイズと同じ決まり)。
3. **コイル副番** の **2ケタ**(例 1-1)か **3ケタ**(例 2-2-1)を選びます。**最初はどちらも選んでいません**(サイズを選ぶ・クリアのたびに戻ります)。選ばずに決定すると「2ケタ、3ケタどちらにもチェックが入っていません」と出ます。
4. **重量** を入れます(指定サイズと同じく小数も入ります。0 より大きい数)。3ケタのときは「重量 1-2-?」「重量 2-2-?」の欄も使います。
5. **決定** を押すと「反映しました」と出て、下の「反映値」に検査番号・サイズ・重量・型番・副番が出ます。
6. **印刷** を押し、確かめの窓で **OK** を押すと印刷用のタブが開き、すぐ印刷の窓が出ます。

- **クリア** は、確かめのあと、その台紙の反映内容を消します。
- 重量を入れなかった段は刷りません。
- 一覧に出るのは、設定の「出すサイズ」で出しているサイズだけです。

## 5. 印刷の位置合わせ(プリンターごとに一度)

ラベルが台紙の枠からずれて刷られるときに、一度だけ合わせます。合わせた値は **このPC** に覚え、次からずっと効きます。合言葉は要りません。

1. 小ラベルの紙面の上の案内で **位置合わせ（試し刷り）** を押します。
2. **試し刷り** を押して、普通紙に 1 枚刷ります(印刷の窓は何も変えません)。
3. 刷った紙を台紙と重ねて明るい所で透かし、点線の枠がラベルの切れ目から **どっちへ何mm** ずれているかを定規で測ります。
4. 「ずれを直す」で、横のずれの向き(**左**/**右**)と量(mm)、縦のずれの向き(**上**/**下**)と量(mm)を入れます。ずれていない向きは 0 か空欄のままで構いません。
5. **直す** を押します。入れた量だけ逆向きに動かして刷るようになります。画面の上に「いまは 右へ 2.5mm・下へ 1.5mm ずらして刷っています」のように、いまの状態が出ます。
6. もう一度試し刷りして確かめます。
7. 終わったら **ラベル印刷へ戻る** で戻ります。

- 少しだけ残ったら「少しずつ動かす」の **↑ 上へ** **← 左へ** **右へ →** **↓ 下へ** で詰めます(1 回に動かす量は 0.1 / 0.5 / 1.0mm)。
- 下の段ほどずれが大きいときは「大きさそのものが合わないとき」を開き、試し刷りの **青い線**(100.0mm のはず)と **赤い十字**(紙の端から 20.0mm のはず)を測って入れ、**この長さで合わせる** を押します。
- 元に戻すときは **最初（ずらさない）に戻す**。
- 試し刷りには全段の境目が赤い線で入っています。一番下の段が合っていれば、段の間隔も合っています。
- 刷ると縮むときは、プリンター側の「用紙に合わせて拡大／縮小」を切ります。

## 6. 版を確かめる

左上の「v1.5.28」と、下の帯に版が出ています。下の帯の **診断** を押すと、版・版を切った日・資材マスタをどこから読んだかなどがまとめて出ます。問い合わせのときに伝えてください。

下の帯の **計算・印刷の記録** では、計算と印刷のたびに、どの取得元(SQLite / Access / CSV / 古い内容)の、いつ時点の資材重量だったかが新しい順に見られます(この PC の分)。どの版で・どの PC(ライン)で、も出ます。種類の **印刷画面** は印刷の画面を開いた記録で、刷った証拠にはなりません。**止めた印刷** は、入力が変わったまま印刷を止めた記録です。下には **資材マスタの編集履歴**(いつ・何を何から何に。このツールから直したときは誰が、も)が出ます。資材マスタ(SQLite)が直されると、資材マスタ自身が自動で書きます(ツールの外で直しても残ります)。記録は月ごとのファイルにも残り、設定の **計算・印刷の記録の保存先フォルダー** を入れるとそこにも PC ごとに書きます(この PC への保存はそのまま)。ファイルは **CSV で、Excel でそのまま開けます**(設定の **記録ファイルの形式** で JSONL・両方にもできます)。見るときは写しを開くか、読み取り専用で開いてください。Excel で開いている間に書けなかった分は「追記待ち」に足し、閉じたあと次の記録で書き足します。設定の **ライン名（このPC）** を入れると、記録にライン名も残ります。**資材重量の変化** は、計算のときに読んだ資材重量が前と変わっていた記録です(ツールの外で直した分も分かります)。

**テストモード**: 実機で試験するときは、設定の **合言葉** のタブの **テストモード（実機の試験中）** にチェックを入れて **テストモードを保存** を押します(合言葉が要ります)。記録と資材マスタの編集履歴に「テストモード」と残り、画面の右上に赤い「テストモード」の札が出ます。**試験が終わったら必ず切ります。**

## 7. 設定

左のタブの **設定** を開きます。「パス設定」「サイズ」「マスタ管理」「配布設定」「合言葉」のタブがあります(1.5.46。合言葉の欄とテストモードは **合言葉** のタブにあります)。

### 7.1 合言葉

フォルダーやファイルの場所を変える・マスタを書き換える・出すサイズを変える・サイズを足す・配布設定を扱うときだけ要ります。印刷の位置合わせには要りません。

- **合言葉** のタブの欄に入れておくと、ほかのタブで押す「保存する」「書き込む」などのときに一緒に送られます(タブを移っても消えません)。
- 合っているかだけ見たいときは **確認する** を押します。
- 入れずに押すと、伏せ字の窓で聞かれます。
- 合言葉は担当者に聞いてください(この文書には書きません)。

### 7.2 サイズを出す・足す

**出すサイズ**(このPCだけ)

1. 設定の **サイズ** タブを開きます。
2. 「指定サイズの画面に出すサイズ」で、出したいサイズにチェックを入れます。チェックを外したサイズは、指定サイズの画面と全サイズの一覧に出ません(いまラインに来ないサイズの選び間違いを防ぐため)。足したサイズ(共有の資材マスタ)は、どの PC にも最初から出ます(外した PC だけ出ません)。
3. **出すサイズを保存** を押します(合言葉が要ります。1 つ以上は出します)。

**新しいサイズを足す**(全ライン)

1. 「新しいサイズを足す」に **厚み(mm)・巾(mm)・型番** を入れます。記号・備考は任意です(備考は指定サイズの画面に赤字で出ます)。
2. 「このPCの指定サイズの画面に出す」は、ふつう入れたままにします(外すと、この PC にだけ出しません)。
3. **サイズを足す** を押します(合言葉が要ります)。
4. 共有の資材マスタ(表「ペナラベル追加サイズ」)に書くので、**どの PC の指定サイズの画面にも出ます**。ラベル台紙一覧に書き足す必要はありません。

**足したサイズを消す**(全ライン)

1. 設定の **マスタ管理** で、表「ペナラベル追加サイズ」を選びます。
2. 消したいサイズの **直す** を押し、**この行を消す** を押します(合言葉が要ります)。
3. どの PC の画面にも出なくなります。行は残して「削除日時」が入ります(番号は新しいサイズで使い回しません)。同じ寸法はもう一度足せます。

注意:

- **サイズ(厚み・巾)はあとから直せません。** 間違えたときは、マスタ管理で消して、正しいものを足し直します。型番・記号・備考は **マスタ管理** の表「ペナラベル追加サイズ」で直せます。
- 資材マスタが SQLite でないとき(CSV で動いているときなど)は足せません。理由が画面に出ます。
- 全サイズの画面の一覧にも出すときは、型番マスタ(表「型番」か型番マスタ CSV)にも同じサイズを足します。
- 足したサイズの巾が 53.5mm なら、11 本 / 10 本でハードボードが HB590 / HB530 になります(同梱のサイズと同じ)。

### 7.3 パス設定

- 資材マスタの参照先・梱包資材マスタ(SQLite)・資材マスタ CSV・型番マスタ CSV・ラベル台紙の寸法・バーコードの出し方などを変えられます。変えたら **保存する**(全部の欄)か、欄ごとの **この欄を保存** を押します。
- **資材マスタへの接続を試す** で、保存せずに読めるか試せます。読めた件数と足りない資材名が出ます。
- 資材マスタ CSV・型番マスタ CSV の **手本を出す** を押すと、欄に入れたパスへ列の見出しと例の行を出します(すでにあるファイルは上書きしません)。Excel で開いて直し、**この欄を保存** を押します。
- 読む順は **DB が先** です。資材マスタは SQLite → Access(ACE)→ CSV、型番マスタは資材マスタ(SQLite)の表「型番」→ CSV。欄の下に「いま読んでいる先」が出ます。
- 「設定の保存先（このPC／複数のPCで共有）」に、ファイルの場所が出ます。**このPCに保存** のもの(この端末の設定・印刷位置の補正・作業の状態)はこのPCだけで使います。**全ラインで共有** のもの(資材マスタ)を変えると、ほかのラインにも効きます。

### 7.4 マスタ管理・配布設定

- **マスタ管理** … 資材マスタ(SQLite)の表の中身を見る・直す。見出しを押すと並べ替えます。書き込む・消すには合言葉が要ります。
- **配布設定** … この端末の設定を、ほかの PC に配る形で書き出します(合言葉が要ります)。

## 8. 困ったとき

| 出たもの・起きたこと | すること |
|---|---|
| 検査NOが7桁入力されていない もしくは …桁目に…が入力されています | 英字 1 文字 + 数字 1 文字 + 英数字 1 文字 + 数字 4 桁で入れ直します(例 N6X0945)。「N桁目」は右から数えた桁です。「W111E11」のように数字の所に英字があっても出ます |
| 検査NOは7桁です(N桁入力されています) / 検査番号は7桁までです | 7 桁で入れ直します |
| 重量入力がありません 丈1(丈2 / 丈1 or 丈2) | 選んだ丈の重量を入れます。丈1・丈2 同時は両方要ります |
| サイズが選択されていません / コイルサイズが選択されていません | サイズを選んでから押します |
| チップボールチェックがありません | チップボールサイズを選びます |
| 本数が入力されていません | 積み本数を入れてから **重量計算_DB** |
| 入力が変わっています。印刷を止めています。 | 指定サイズの画面で **重量計算_DB** を押し直してから刷ります |
| NW が思った値と違う | 重量を変えたあと重量反映をしていない可能性があります。**重量反映** → **重量計算_DB** の順で押し直します |
| 印刷するラベルがありません | その台紙に重量反映していません。**重量反映** をしてから刷ります |
| 資材重量なし / 資材重量なし: 資材マスタに無い資材、または単重・係数が数でない資材があるので、計算を止めました | 資材マスタを読めていないか、マスタに無い資材・単重が数でない資材があります。設定の **資材マスタへの接続を試す** か、下の帯の **診断** を見て、担当に伝えます |
| 右上の札に「（古い内容）」 | 資材マスタを読み直せず、前に読んだ内容で計算しています。共有フォルダーにつながるか確かめ、担当に伝えます |
| ラベルが台紙の枠からずれる | 5 章の位置合わせをします |
| 印刷ビューが開かない | 確かめの窓の **OK** を押したか確かめます。開かないときはブラウザがポップアップを止めていないか確かめます |
| バーコードの所に `*…*` の文字だけが刷られる・赤い警告が出る | バーコードの出し方が「フォント」で、フォントが置かれていません。担当に伝えます(設定で「svg」に戻すと直ります) |
| この画面は開けません / この画面は使用中ではなくなりました | ペナラベルは 1 つの画面でしか使えません。先に開いた画面を使います。見当たらないときだけ **この画面で使う** |
| 接続なし — 再読込してください | 画面を読み込み直します(F5)。直らなければアプリを開き直します |
| サイズを足せません | 理由が画面に出ます。資材マスタが SQLite でない・読み取り専用などのときは担当に伝えます |
| エラー番号 E… | 番号を伝えてください。統合画面の **ログ** で中身を見られます |
