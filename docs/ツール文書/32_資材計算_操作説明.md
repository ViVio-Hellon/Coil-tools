# 資材計算 操作説明

対象の版: 資材計算 0.2.24(コイル梱包ツール 1.2.26)

ロットから、パレット・リプラ・緩衝材の数を出し、チェックリストに積んで発注票を作るまでの使い方です。
統合画面の **資材計算** タブで使います。写真つきの説明は、上の帯の **説明書** → 資材計算(`templates/manual/material.html`)にあります。
この文書はそれと同じ手順を、文字だけで少しくわしく書いたものです。

---

## 1. 画面の見方

### 上の帯

| 出るもの | 使い方 |
|---|---|
| 版(`VER0.2.22`) | 押すと 設定 → 「このアプリ」が開きます |
| マスタ | 取り込んだ日時です。「古い」と出たら取り込みをします(朝いちばんに 1 回) |
| ライン | LS4 / NS1。選ぶとすぐ覚えます(チェックリストの表題に出ます) |
| 担当者 | 自分の名前を選びます。**選んでいないとチェックリストに積めません** |

### 左のメニュー

**資材計算** → **チェックリスト** → **発注票** → **設定**。上から順に使います。

### 色と印

| 見え方 | 意味 |
|---|---|
| 黄色い入力欄 | ここを入れる欄です(LotNo・検入数・コイル外径) |
| 見出しが赤字で ● が付く | その規則で決まりました(重量 / 枚数 / 高さ / 包装仕様) |
| 値が青い枠で囲まれる | 1 本積みができず、台数を分けました |
| 2 つの「リプラ種類」が赤字で ● | 最下部とコイル間でリプラの種類が違います。取り違えないように |

自分で打つ 4 つの欄(LotNo・受注番号・検入数・コイル外径)は、ほかより大きな字です。字が大きいほうが「打つ場所」です。

## 2. 毎日の流れ

### 2.1 はじめに(朝)

1. 帯の **マスタ** に「古い」が出ていないか見ます。出ていたら、左の **設定** → **取り込み** の面で **いま取り込む** を押します。
   - 仕掛台帳は日ごとの台帳なので、日付が変わると中身も変わります。夜勤で日付をまたいだときも「古い」が出ます(札にカーソルを合わせると理由が出ます)
2. 帯の **ライン** と **担当者** を選びます。選んだ時点で保存されます(保存ボタンはありません)。

### 2.2 資材の数を出す

1. **LotNo**(7 桁)を入れます。小文字で打っても大文字になります。7 桁そろうと自動で探し、受注番号の候補が出ます。
2. **受注番号** を選びます。候補が 1 つなら自動で選ばれます。厚・幅・材質・包装仕様No・製品単重などが出ます。
3. **検入数**(本)を入れます。1 以上の整数で入れます(小数・0・負の数は断られます)。
4. **コイル外径**(mm)を確かめます。受注の外径 MAX が入っていますが、打ち直せます。
5. **計算Start** を押します。「台数 N 台 / ﾘﾌﾟﾗ N 本」と出ます。

検入数は欄を離れたときに送られますが、入れてすぐ **計算Start** を押しても、入れた検入数で計算されます。

計算のあとで **検入数・コイル外径を入れ直すと、前の計算結果は消えます**(「検入数・外径が変わったので前の計算結果を消しました」)。もう一度 **計算Start** を押します。古い結果のままチェックリストへ積まないための決まりです。

### 2.3 結果を読む

**2. 計算結果** に次のものが出ます。

- パレット種類・パレットサイズ・パレット名称
- 積数(本/台)・台数。1 本積みができず分けたときは「別枠 積数 / 台数」も出ます
- 総高さ(高さで決まったときなど)
- コイル間・ﾘﾌﾟﾗｻｲｽﾞ・緩衝材・HB枚数
- **ﾘﾌﾟﾗ総本数** … 発注するのはこの数です(下の 2 つの枠を足したもの)

リプラは 2 つの枠に分かれています。どちらの本数かを取り違えないためです。

- **最下部(パレットの上)** … 長 / 短 を列にした表です。**1 列を上から下に読めば 1 組**(長さと、その本数)です
- **コイル間** … コイルどうしの間に敷くリプラの長さと本数です

### 2.4 包装仕様書を見る

1. 包装仕様No(青い下線の文字)を押します。番号がコピーされ、閲覧システムが別のタブで開きます(デスクトップ版では、いつものブラウザで開きます)。
2. 閲覧システムの検索欄に **Ctrl+V** で貼り付けて探します(閲覧システムには番号が渡らないため)。

### 2.5 チェックリストへ積む

1. **ﾘﾌﾟﾗ総本数** を確かめます。
2. サイズが確定している品物なら **ｻｲｽﾞ確定品** にチェックを入れます(チェックリストの「確定」欄に `〆` が付きます)。
3. **チェックリストへ積む** を押します。「チェックリストの N 行目に積みました」と出ます。空いている最初の行に入ります。15 行まで積めます。
4. 次のロットへ。LotNo を打ち直すと、前の入力と結果は消えます。全部消したいときは **はじめから** を押します。

### 2.6 チェックリストを確かめる・印刷する

1. 左のメニューの **チェックリスト** を開きます。積んだ行が並びます(「N / 15 行」)。
2. いらない行は右端の **消す** で消します(確かめが出ます)。
3. **印刷** を押すと、紙面が別の窓(ブラウザ版では別のタブ)で開きます。上の **印刷する** を押すと印刷のダイアログが開きます(Ctrl+P と同じ)。
   - A4 横・1 ページです。倍率は 100% のままにします。ボタンと案内は紙には出ません
4. 全部空にしたいときは **全部消す**(確かめが出ます)。

### 2.7 発注票を作る

1. チェックリストの **発注票へ**、または左のメニューの **発注票** を開きます。
2. **発注票を作る** を押します。「N 枚作りました」と出ます。リプラの角サイズ(30×40 / 40×60 / 80×80)ごとに 1 票です。
   - 対象はコイル間が「リプラ」「LVS」の行だけです
   - 長さの行は、梱包資材マスタの表「リプラサイズ」の長さです。定尺に無い長さは下の空欄 4 行に書き足され、
     「倉庫の定尺にない長さを書き足しました」と出ます。**5 件以上あると作れません**
3. 「**2週間以内に発注あり**」と出たら、同じロットをもう発注しています。票の中身は先に見えるので、それを見て
   重複してよければ **このまま作る**、やめるなら **やめる** を押します。

### 2.8 発注票を印刷する

1. **印刷** を押すと紙面が開きます。上の **印刷する** で印刷のダイアログを開きます。
2. ダイアログで**用紙の向きが「横」**になっているか確かめます。
3. A4 横 1 枚につき 1 票が、紙の**左半分**に出ます。真ん中の縦の切り取り線で切ると **A5 縦** の票になります(右半分は空白です)。

### 2.9 履歴に残す

1. 刷って出したら **発注済みとして記録** を押します(確かめが出ます)。「N 件を履歴に残しました」と出て、「記録済み」に変わります。
2. **押すまでは履歴に残りません。** 記録した発注は、次から「2週間以内の同じロット」を見つけるのに使います。
3. 同じ票を 2 度は記録できません。もう一度記録するときは、発注票を作り直します。
4. 記録した発注は、発注票の画面の下の **発注の履歴** を開くと見られます(新しい順に 200 件まで)。**LotNo で絞る** にロット番号を打つと、そのロットの発注だけが出ます。記録した直後にも、ここへすぐ出ます。

作った発注票は、記録するまでサーバのメモリにだけあります。統合画面を閉じようとすると「まだ保存していない入力があります」と確かめが出ます。

## 3. バリ揃え梱包

上向きのバリと下向きのバリを混ぜて積めない品のときに使います。

1. 先にふつうに **計算Start** まで済ませます(検入数・製品単重・包装仕様が要ります)。
2. 計算結果の右下の **バリ揃え梱包…** を押すと、「3. バリ揃え梱包」の窓が開きます。
3. **上バリ（本）** と **下バリ（本）** を入れます。打ち込むか、欄の左右の **−** **＋** で変えます(手袋のままでも押せます)。
   0 より下へは行きません。上下の合計は検入数を超えないように詰められます。
4. **押しただけでは計算しません。** 数を決めてから、窓の中の **計算Start** を押します。残り検入数・積数・上台数・下台数・台数が出ます。
5. よければ **結果転送** を押します(確かめが出ます)。積数と台数が計算結果へ送られ、パレット・リプラも計算し直されて、窓が閉じます。前の計算の「別枠 積数 / 台数」は消えます。
6. 送らずに戻るときは **閉じる** を押します。

> オーダーの重量から積数を出すとき、バリ揃えは**切り上げ**、ふつうの計算は**切り捨て**です(元の VBA のまま。理由は確かめ中)。
> 結果転送のあとは、計算結果の積数・台数を見直してください。

## 4. 単重再計算

引当の製品単重が当てにならないときに、外径・内径・幅・比重から 1 本の重さを計算し直します。

1. **単重再計算** を押します。「単重を再計算します」と確かめが出るので、OK を押します。
2. 「再計算した単重」の欄に出ます(小数 2 桁で切り捨て)。
3. 製品単重そのものは**書き換えません**。計算Start の計算にも使いません。見比べるための値です。

内径・外径・幅・比重のどれかが無いと「指定項目に入力がありません(…)」と出ます。

## 5. 積数の手直し

規則で出た積数を、現場の判断で変えたいときに使います。

1. 計算結果の **積数（本/台）** の欄に数を打ち、欄を離れます(Tab など)。
2. 「積数から台数を出し直しました」と出て、**台数 = 検入数 ÷ 積数 の切り上げ** で出し直され、リプラも計算し直されます。
   前の計算の「別枠 積数 / 台数」や印は**消えます**(手で入れた積数だけが残ります)。
3. 規則(重量・枚数・包装仕様No 別・高さ)では**上書きしません**。もう一度 **計算Start** を押すと、規則どおりの積数に戻ります。

積数には 1 以上の整数を入れます。0 や小数は断られます。断られたときは計算結果が空になるので、そのままチェックリストへは積めません。

> 以前(VBA のころから)は、1 本積みができず分けたあとに積数を直すと、前の「別枠」が残って台数を二重に数えていました。
> (例: 検入数 13 本・枚数 4・1不可 → 3 台 + 別枠 2 台 に分かれたあと、積数を 5 に直すと、3 台のはずが 5 台)。統合 1.2.26 で直しました。

## 6. マスタ管理(包装仕様・パレット・リプラサイズを直す)

1. 左のメニューの **設定** → **マスタ管理** を開きます。見るだけなら、そのまま見られます(「見るだけ」と出ています)。
2. 表の一覧から見たい表を押します。直せるのは **包装仕様・パレット・リプラサイズ** の 3 つです。
3. 絞り込みの欄で、どの列の文字でも探せます(例: 1C1188 / スカシ / リプラ)。見出し(列名)を押すと並べ替わります(▲ 小さい順 / ▼ 大きい順。数は数の大きさで、空はいちばん後ろ)。
4. 直すときは、先に**設定のいちばん上**で合言葉を入れて **認証する** を押します。「直せます」に変わり、**+ 行を足す** が押せるようになります。
5. 行を押すと、その 1 行の窓が開きます。直して **取り込み元へ書く** を押します。行を消すときは **× この行を消す**(戻せません)。

気をつけること:

- 書く先は手元の写しではなく、**共有フォルダの元の梱包資材マスタ**です。ほかのラインの端末にも効きます。保存の前に一度読み直してください
- **30 分さわらないと認証が閉じます。** 続けて直すときは、もう一度合言葉を入れます
- 班員名簿など、このツールで直さない表は「見るだけ」のままです(日報ツールなど、持ち主の側で直します)
- 合言葉は **マスタ管理** の面の「パスワードを変える」で変えられます(今の合言葉が要ります)。このPCだけのものです

## 7. 取り込みと設定

### 7.1 取り込み

**設定** → **取り込み** の面です。

- **起動したときに自動で取り込む** … チェックを入れておくと、起動のたびに取り込みます(更新されたファイルだけ。待機画面に進み具合が出ます)
- **いま取り込む** … すぐ全部を取り込みます。終わるまで「取り込んでいます…」になり、終わると件数が出ます
- 表ごとの取り込み日時と件数が出ます。「未取り込み」があれば取り込みます

### 7.2 取り込み元の置き場所

同じ **取り込み** の面にあります。**変えるには合言葉が要ります**(設定のいちばん上で認証)。

1. 欄に置き場所を打ちます(梱包資材マスタのフォルダ / 仕掛台帳のフォルダ / 仕掛台帳(2つ目)のフォルダ / 2つ目の名前)。
2. その欄の **確かめる** を押します。届くか・目当てのファイルがあるかが欄の下に出ます。
3. よければ **この欄を保存**。保存は欄ごとです。
4. **保存しただけでは手元のデータは変わりません。** 置き場所を直したら **いま取り込む** を押します。

仕掛台帳(2つ目)は、1 つ目で見つからないときに見る先です。空のままでかまいません。

### 7.3 ラインと担当者

**設定** → **ラインと担当者** の面でも選べます(帯の欄と同じです)。担当者は梱包資材マスタの「班員名簿」のうち、担当ラインが機側の人です。

### 7.4 たくさんの端末に配る(配布設定)

1. 1 台で置き場所などを決めたら、設定のいちばん上で認証し、**配布設定** の面で **配布設定を書き出す** を押します。
2. 統合アプリのフォルダの `配布設定\packing_material_calculation` にできるので、フォルダごと配ります。
3. 配った先は起動したときに読み込みます。その端末にすでにある設定は上書きしません。揃え直すときは、その端末で **配布設定を読み込み直す**。

ラインは既定では入れません(端末ごとに違う)。担当者は入れられません(人ごとに違う)。

### 7.5 保存先・版

- **保存先（このPC／共有）** の面に、設定ファイル・作業用DB・ログ・共有のマスタの実際の場所が出ます
- **このアプリ** の面に、版・置き場所が出ます。問い合わせのときはこの画面を見ながら伝えてください

## 8. 困ったとき

| 出たもの・起きたこと | すること |
|---|---|
| そのロットに紐づく受注がありません | 台帳を取り込めていないか、まだ台帳にないロットです。設定の **いま取り込む** をして、もう一度入れます |
| 検入数を入力してください | 検入数を入れてから **計算Start** |
| 検入数には1以上を入れてください | 0 や負の数は使えません。数え直して入れます |
| 検入数が1本のため、1本積み不可の振り分けができません | 1 本積み不可の品で検入数が 1 本です。積数の欄に手で数を入れます(5 章) |
| 検入数・外径が変わったので前の計算結果を消しました | 入れ直したので古い結果を消しました。**計算Start** を押し直します |
| 検入数は整数で入力してください / 積数は整数で入力してください | 小数を消して整数で入れ直します |
| 引当データなし。計算ができません | 受注に梱包単位(重量・枚数)がありません。オーダーの側のデータを待ちます |
| 包装仕様No … がマスタに登録されていません | 梱包資材マスタに無い包装仕様です。マスタの担当に伝えます |
| 外径 … が収まる「…」のパレットがマスタにありません | 外径の打ち間違いか、マスタの登録漏れです。外径を確かめます(ﾎｲｰﾙはここで計算が止まります。ほかの種類はパレット欄が空のまま続きます) |
| 積数が 0 になりました / 高さの制限に収まる積数がありません | 製品単重と梱包単位・梱包総高さの指定を確かめます。マスタの担当に伝えます |
| 担当者を選んでください(帯の担当者欄) | 上の帯の担当者で自分の名前を選びます |
| 先に計算してください | **計算Start** で台数を出してから積みます |
| チェックリストが15行埋まっています | 発注票を作るか、いらない行を消します |
| 発注リストにないサイズが多すぎます | 定尺に無い長さが 5 件以上あります。マスタの「リプラサイズ」に長さを足すか、チェックリストを分けて作ります |
| チェックリストに、発注票にできる行がありません | コイル間がリプラ / LVS の行がありません |
| 先に発注票を作ってください | **発注票を作る** を押してから記録します |
| この発注票は記録済みです | もう記録してあります。もう一度記録するときは作り直します |
| 帯に「古い」 | 設定の **いま取り込む** を押します |
| 担当者の一覧に自分が出てこない | 設定の **ラインと担当者** の担当者欄の下を見ます。「内蔵の一覧を出しています」と出ていたら **いま取り込む**。それでも出なければ、日報ツール側の名簿に登録(担当ラインは機側)してから取り込みます |
| マスタを直すにはパスワードが要ります / 置き場所を変えるにはパスワードが要ります | 認証していません。設定のいちばん上で合言葉を入れます |
| すでに別の画面で開いています | 資材計算は 1 つの画面でしか使えません。もう一方を使うか **この画面で使う**(もう一方の入力の途中は消えます) |
| この画面は使われなくなりました | 別の画面で「この画面で使う」が押されました。続けるときは、もう一度 **この画面で使う** |
| 起動しています | 準備が終わるまで少し待ちます |
| エラー番号 E… | 番号を伝えてください。統合画面の **ログ** で中身を見られます |
