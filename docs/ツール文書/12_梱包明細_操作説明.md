# 梱包明細 操作説明

対象の版: 梱包明細 VER 0.13.35(コイル梱包ツール 1.2.57)

ロットを開いて重量を入れ、積む順にコイルを押して **梱包明細表** を出す手順です。
統合画面の上の帯の「説明書」(写真入り。`templates/manual/details.html`)と同じ流れで書いています。決まりの細かいところは [11_梱包明細_仕様.md](11_梱包明細_仕様.md) を見てください。

## 0. 開く・閉じる

- コイル梱包ツールのフォルダの `Start.vbs` をダブルクリックし、上のタブの **梱包明細** を選びます
- 終わるときはブラウザのタブを閉じるだけで構いません。帳票を開いた別のタブが残っていれば、それも閉じてから裏側が終わります
- 別のタブに切り替えても、最小化・画面ロック・スリープをしても終わりません
- **途中で閉じても大丈夫です。** 条番号を出した時点・廃棄を付けた時点・出力した時点で保存してあるので、同じロット番号を入れ直せば続きから始まります

> 梱包明細は **同時に 1 枚しか開けません**。2 枚目を開くと「この画面はすでに開いています」と出ます(§8)。

## 1. 画面の見方

| 場所 | 中身 |
|---|---|
| 上の帯 | 題名・版(押すと「バージョン情報」)・台帳を取り込んだ日時 |
| 左のタブ | **取り込み**・**履歴**・**マスタ管理**・**設定**・**説明書**(文字だけの詳しい説明書) |
| 本体の左 | ロット → 丈数と重量 → 条番号 |
| 本体の右 | 積み上げ(出力・印刷・全クリア)→ 出力済み(出力済み修正) |

## 2. 明細表を出す(毎日の作業)

### 手順 1 ロットを開く

1. **ロット番号** に 7 桁を入れます。小文字は大文字に直ります。7 桁そろうと自動で探します
2. **割数**(例: 縦割2 × 横割12)と **前工程実績数** が自動で入ります。違うときは **修正する** を押して直し、**確定する** を押します
3. 用途・材質・板厚・板幅などロットの情報が出ます。合っているか確かめます
4. 受注番号が並びます。押すと **包装仕様NO** が切り替わります。包装仕様NO を押すと、番号をコピーして包装仕様書の画面が開くので、貼り付けて検索します

> **コツ** 同じロットを前に途中までやっていたときは「前回の条番号情報を復元しました」と出て、続きから始まります(積み条数は入れ直します)。

> **前工程実績数が 0 のとき** そのロットが梱包課共有の仕掛(LS4LOT)に載っていません。**修正する** で手で入れて **確定する** を押します。

### 手順 2 重量を入れる

1. **丈数** はふつう自動で入ります(縦割数)。**−** **＋** で直せます。丈数を変えると、重量・条番号・積み上げ・廃棄は最初からになります
2. **丈ごとの重量** を **整数で** 入れます。下の **-10** **-1** **+1** **+10** でも増減できます。欄を離れたときにサーバへ送ります
3. **条番号表示** を押します。条番号と積み上げの欄が出ます

- 小数点は使えません。入ると欄が赤くなり「整数で入力してください」と出ます。消して入れ直してください
- 全角の数字は半角に直ります。0 は受け付けません

**反転** は条番号の並びを左右逆にします。番号は変わりません(現物の向きと画面の向きを合わせるためのものです)。
**廃棄選択** を押している間(ボタンが「廃棄選択中」になります)は、押したコイルに廃棄の印(×)を付け外しできます。もう一度押すと元に戻ります。廃棄したコイルは積めません。

### 手順 3 積む順にコイルを押す

1. **積み条数**(1〜15)を入れます。**−** **＋** でも変えられます。右に同じ数の枠ができます
2. **条番号** のコイルを、積む順に押します。押したコイルは色が変わります
3. **積み上げ** に下から入ります(下がスロット 1 = 最初に積むもの)。間違えたら、積み上げの枠を押すと外せます。外した枠は空いたまま残り、次に押したコイルがそこへ入ります

- 使用済み(色が変わったもの)のコイルは押しても何も起きません
- 積み始めてからでも積み条数を変えられます。積んだコイルはそのまま残ります。減らすときに、無くなる枠にコイルが入っていれば「先に解除してください」と出ます(VER 0.13.33)

### 手順 4 出力する

1. 積み上げの枠が全部埋まったか確かめます。**全部埋まるまで「出力」は押せません**
2. **出力** を押します。すでに出力した副番が入っているときは確かめの窓が出ます(§4)
3. 「出力しました。No1を確認してください。」と出ます
4. **出力済み** に「ロット番号-No」が並びます。積み上げは空に戻り、使ったコイルは「使用済み」の色のまま残ります(同じコイルを 2 回積まないため)
5. 続けて次の梱包を積むときは、手順 3 からくり返します

### 手順 5 印刷する

1. **印刷** を押すと、紙面が別のタブ(デスクトップ版では別の窓)で開きます
2. 必要ならサイズ・LOTNO を書き足します(§3)
3. **印刷する**(または Ctrl+P)を押します

> **注意** 印刷の窓では **用紙 A4横・余白なし・倍率100%** のままにします。明細表は用紙の左半分に出ます(右半分は空白。切り取って使います)。ボタンや案内の文字は紙には出ません。左や上が欠けたら、倍率が 100% になっているか見てください。

- **まとめて刷る**: 「出力済み」のチェックを入れて **印刷 (N枚)** を押します。1 枚ずつ別の用紙に、No の順に出ます
- 「印刷」を押した時点で「印刷した」と記録します。紙面を閉じて刷らなかったときは、別のロットへ移る前にもう一度刷ってください

## 3. 紙面での書き足し

1. 開いた紙面の「寸法」「検番」の行に点線の欄があります。押すと **サイズ**・**LOTNO** を書き足せます
2. 打って Enter(または欄の外を押す)で「保存しました」と出ます
3. **印刷する** を押します

- 空のままなら何も刷りません
- 1 欄 20 文字まで。長いと理由が出て受け付けません
- 書き足した内容はその明細に残ります。刷り直しても出ます(ロットを切り替えると明細と一緒に消えます)
- まとめて開いたときは、それぞれの明細に書き足せます
- 点線と灰色の「サイズ」「LOTNO」は画面のときだけで、紙には出ません
- 「この明細は作り直されたか、もうありません」と出たら、出力済み修正で同じ No を出し直した後の古い紙面です。「出力済み」から紙面を開き直してください

## 4. よく出る確かめの窓

| 出る文 | 意味と押すボタン |
|---|---|
| 前回の出力(…)がまだ印刷されていません。シートを削除してよいですか？ | 出力したのに印刷していないまま、別のロットを開こうとしました。印刷が済んでいれば **はい**。まだなら **いいえ** で戻って印刷します |
| 以下の副番はすでに出力済みです。このまま出力しますか？ | 同じコイルを 2 回出そうとしています。刷り直しなら **はい**、押し間違いなら **いいえ** |
| 前回の状態が復元されています。条番号を再表示すると、出力していない使用済みはリセットされます。 | 続きから使うなら **いいえ**。条番号を出し直すなら **はい**(出力済みのコイルと廃棄は残ります) |
| No…を積み直した並びで出し直します。前の No… の紙は使えなくなります(刷り直してください)。 | 出力済み修正の「修正して出力」。前・後の並び、外すコイル・加えるコイルを見て、よければ **はい**(§5) |
| No…の修正をやめますか？(紙は前のままです) | 「修正をやめる」を押しました。**はい** で修正前に戻ります |
| ロット … を初めからやり直します。… よろしいですか？ | 「全クリア」を押しました。出力済みもまとめて消えます(§5) |

## 5. 出力済み修正・全クリア

### 出力済み修正(出した 1 枚を積み直す)

出したあとで積み順やコイルの間違いに気づいたときに使います。**同じ No のまま** 出し直します(連番は進みません)。

1. **出力済み** で、直したい 1 枚に **だけ** チェックを入れます(2 枚以上・積み上げ中のコイルがある・条番号を出していないときは押せません。理由がボタンの横に出ます)
2. **出力済み修正** を押します。積み上げの上に「No…を修正中」と出て、その No のコイルが積み上げに戻ります
3. 積み上げの枠を押して外し、コイルを押して積み直します。積み条数も変えられます
   - **ほかの No で使っているコイルは積めません**(No1〜No3 があって No1 を直すとき、No2・No3 のコイルは灰色のままで、押しても積まれません)
4. **修正して出力** を押し、確かめの窓で **はい**
5. **印刷** で刷り直します。前に刷った紙は使いません

- やめるときは **修正をやめる**(紙は前のまま)
- 修正しているあいだは **条番号表示**・丈数・前工程実績数・重量は変えられません(重量は VER 0.13.35 から。重量を直すときは全クリアから)。修正中の No のコイルは廃棄にできません。ロット番号を入れ直すときは、修正をやめるか確かめます
- 修正中の重量は、その No を出したときの値です。修正を終えると画面の重量と積み条数は入る前の値に戻ります
- 書き足したサイズ・LOTNO は新しい紙に引き継ぎます。前の紙は明細の履歴に「作り直し」と残ります

### 全クリア(初めからやり直す)

**全クリア** を押すと、開いているロットの **出力済み・副番の記録・連番・条番号と廃棄** をまとめて消し、No1 から初めからやり直します。何枚消えるかが出るので、よければ **はい**。

- ロットは開いたまま、丈数・前工程実績数は台帳の値に戻ります。**条番号表示** からやり直します
- 明細の履歴は消さず、「取り消し」と残します(CSV の集計では枚数に数えず「取り消した枚数」に出ます)

### そのほか

- **No指定** と **副番履歴クリア** は VER 0.13.23 で外しました。副番履歴だけ消すと、No1〜No3 で使ったコイルを No4 へまた積めてしまうためです。1 枚の間違いは出力済み修正、何枚も崩れたときは全クリアを使います
- 条番号を出し直しても、出力済みのコイルは使用済みのままです(VER 0.13.23 から)
- **積み上げを始めたロットは丈数・重量・前工程実績数を変えられず、「条番号表示」も押せません**(丈数は VER 0.13.24、前工程実績数は 0.13.25、重量と条番号表示は 0.13.35 から)。丈数・重量の欄と「修正する」「条番号表示」が止まり「変えるときは「全クリア」してから」と出ます
- 積む前に前工程実績数を「修正する」で変えると、条番号の並びが消えます。**条番号表示** を押し直してから積みます(VER 0.13.26。古い並びのまま積むと、無いコイルを紙に載せてしまうため)
- 全クリアで「取り消し」になるのは、その時点で出力済みにある紙だけです。前に作り直された紙は「作り直し」、前の全クリアで取り消した紙は「取り消し」のまま残ります
- **別のロットへ切り替えると**、前のロットの出力済み・副番の記録・連番・途中経過は消えます(明細の履歴には残ります)

## 6. 台帳を取り込む

1. 左のタブの **取り込み** を押します。「取り込み中」の窓に、いま読んでいる台帳・進み具合・経過秒が出ます。終わると自動で閉じます
2. 取り込んだ件数が出て、上の帯の日時が新しくなります

- 「仕掛台帳がまだ取り込まれていません」と出たときや、ロットが見つからないときは、まず取り込みをします
- 開いていたロットは取り込み前の内容のままです。新しい台帳で引き直すには、ロット番号を入れ直します(手で直した前工程実績数は入れ直しになります)
- 共有フォルダに届かない PC では「届かない」と出ますが、前に取り込んだ分はそのまま使えます
- 取り込み中の窓は Esc で閉じません(閉じても取り込みは止まらないため)

## 7. 履歴から紙面を作り直す

全ラインで出した明細表の記録(3 年分)から探して、紙面を作り直せます。

1. 左のタブの **履歴** を押します。上に共有の履歴の枚数と、この PC の送り残しが出ます
2. **はじめ・おわり(出力日)** を入れます(最初は今月 1 日〜今日)。**ロット番号**(前方一致)や **副番**(例 `1-10`)でも絞れます
3. **探す** を押します。見つかった紙が新しい順に並びます(出力済み修正で出し直された前の紙は「作り直し」、全クリアで消した紙は「取り消し」と出ます)
4. 作り直したい行を押して選びます(もう一度押すと外れます)
5. **選んだ紙面を開く** を押します(一度に 20 枚まで)。「履歴から作り直した紙面です(書き足しはできません)」と出る紙面が開きます
6. **印刷する** を押します

- **CSVに書き出す**: CSV の出力先(既定はアプリのフォルダの `export\packing_details`)に、明細と集計の 2 つを書きます。画面に場所が出ます(**場所をコピー** で写せます)。ブラウザのダウンロードではなく、Excel やフォルダも開きません。開くときはその場所から開いてください
- **いま送る**: 送り残しをすぐ送ります。時間がかかるときは裏で続けます
- 共有に届かないときの「探す」は、この PC の分だけになります(画面にそう出ます)

## 8. 画面が 1 枚しか開けないとき

- 2 枚目を開くと「この画面はすでに開いています」と出て、業務の画面は出ません。先に開いた画面(別のタブかウィンドウ)を使います
- 同じタブの再読込(F5)は断られません
- 先に開いた画面が見当たらない(閉じ忘れ・固まった)ときだけ **この画面で使う** を押します。前の画面から移ります(2 枚になるのではありません)
- 前の画面が閉じられたら「前の画面は閉じられました」と出ます。**もう一度ためす** で続けられます
- 移られた側の画面は「この画面は引き継がれました」と出て止まります。途中経過は保存してあるので、新しいほうで同じロット番号を入れ直せば続きから始まります

## 9. マスタ管理(見るだけ)

1. 左のタブの **マスタ管理** を押します
2. 上の **梱包資材マスタ**・**梱包明細履歴** で見るファイルを選びます
3. 左の一覧で表を選ぶと(数字は行数)、右に中身が出ます

- 1 回に出すのは 200 行です。**絞り込む**(どの列でも、一部でよい)と目当ての行が出ます
- 見出しを押すと並べ替え(▲ 小さい順 / ▼ 大きい順)。数字は数の大きさで並びます
- 行を押すと、その 1 行の中身が全部出ます
- **この表をCSVに書き出す**: いまの絞り込み・並べ替えのまま、全行を CSV の出力先に書きます
- **見るだけです。** 梱包資材マスタを直すのは梱包資材総合ツールのマスタ管理です
- 「共有フォルダに届きません」「見つかりません」と出たら、**設定で置き場所を変える** を押すと設定の「梱包資材マスタのフォルダ（共有）」の欄が開きます

## 10. 設定

左のタブの **設定** を押すと、上のタブで中身を切り替えられます。**保存は欄ごと** です。

| タブ | すること |
|---|---|
| 置き場所・取り込み | 第1パス(仕掛台帳・梱包課共有の仕掛と LS4LOT の名前)・第2パス(仕掛4ファイル)・CSV の出力先・梱包資材マスタのフォルダ(共有)・明細の履歴のフォルダ・管理者パスワード・控えのフォルダ |
| 紙面の右上の文字 | 明細表の右上に赤く刷る文字(全ラインで共有) |
| 管理者パスワード | 右上の文字・共有の場所・配布設定を変えるための管理者パスワード(全ラインで共有) |
| 配布設定 | この PC の設定を、ほかの PC に配る形で書き出す |
| 保存先（このPC／共有） | 設定やデータがどこに保存されているか |

### 置き場所を変える

1. 欄に場所を入れます(空にすると既定の場所に戻ります。欄に薄く既定の場所が出ています)
2. 仕掛台帳・梱包課共有の仕掛は **保存して取り込み**、ほかは **保存** を押します
3. 結果はその欄のすぐ下に出ます。見つからなければ赤で、どのファイルが無いかが出ます

- 共有の 3 つの欄(梱包資材マスタ・明細の履歴・管理者パスワードと控え)は、管理者パスワードが要ります
- **第1パス**は、仕掛台帳のフォルダ(SIKALOT・SIKAHIKI・SIKAODR)と、梱包課共有の仕掛フォルダ(LS4LOT)の2つです。LS4LOT は名前も変えられます(空なら LS4LOT.sqlite3)
- **第2パス**は、第1パスで見つからないときに見る先です(4ファイル共通のフォルダ)。4つともファイル名を変えられます(空なら使いません)
- どの置き場所のファイルも、この PC へ写してから読みます(共有のファイルを開いたままにしません)
- ここで変えても、ほかの PC は変わりません。そろえるときは配布設定を使います

### 起動時の自動取り込みを切り替える

同じ **置き場所・取り込み** の面の「起動時の自動取り込み」のチェックを入れる・外すと、すぐ保存されます(このPCだけ)。

- 入れている(既定): 起動したとき、仕掛台帳・梱包課共有が前回から新しくなっていれば取り込み直します
- 外している: 起動したときは取り込みません。要るときは左のタブの **取り込み** で取り込みます

### 紙面の右上の文字を変える

1. **いま刷る文字** と、どこから読んだか(梱包資材マスタ・控えの JSON・既定)が出ています
2. **新しい文字** を入れます(20 文字まで)
3. **管理者パスワード** を入れます(知らない場合は管理者に聞いてください)
4. **保存** を押します。全ラインで、次に開く紙面から効きます。元に戻すときは **既定に戻す**

「共有に届きません」と出たときは、印刷はそのまま(この PC が最後に読んだ文字で)できますが、変えることはできません。

### 配布設定

1. 1 台で「置き場所・取り込み」を決めます
2. **配布設定** のタブで、入れる項目を選びます
3. 管理者パスワードを入れて **配布設定を書き出す** を押します
4. アプリのフォルダの `配布設定\packing_details` にできるので、アプリのフォルダごと配ります(`export` フォルダは外してから)

- 配った先では、起動したときに **その PC にまだ無い設定だけ** 読み込みます
- そろえたいときは、配った先で **配布設定を読み込み直す**(すでにある設定も上書き)

### 作業の記録・ライン名・テストモード(0.13.30)

「置き場所・取り込み」に 3 つの欄があります(どれもこの PC だけ)。

- **記録の保存先フォルダー**(管理者パスワードが要る): 出力・出力し直し・修正の開始/取り消し・全クリア・印刷画面・紙面を開いた の記録を、この PC の records に加えて、ここにも PC ごとに書きます(月ごとのファイル。足すだけで消しません)。共有フォルダーを入れると、PC を入れ替えても残ります。**作業の記録を見る** で記録の画面が開きます
- **記録ファイルの形式**(パスワードは要らない): **CSV(既定。Excel でそのまま開ける)**・JSONL・両方 から選びます。見るときは写しを開くか、読み取り専用で開きます。Excel で開いている間に書けなかった分は「追記待ち」に足し、閉じたあと次の記録で書き足します
- **ライン名（このPC）**: 記録と編集履歴に PC 名と一緒に残ります
- **テストモード（実機の試験中）**(管理者パスワードが要る): 入れると、記録・明細の履歴・編集履歴に「テストモード」と残り、上の帯に赤い「テストモード」の札が出ます。**試験が終わったら必ず切ります**

記録の「印刷画面」は「印刷」を押した記録で、刷った証拠にはなりません(ブラウザは、刷ったか・やめたかを教えません)。

## 11. 版を確かめる

上の帯の **VER …** を押すと「バージョン情報」が出ます。版・**実行フォルダ**・手元の DB・ログの場所・台帳を取り込んだ日時が出ます。問い合わせのときに伝えてください。「変更履歴」で、その版で何が変わったかも読めます。

## 12. 困ったとき

| 出たもの・起きたこと | すること |
|---|---|
| 該当するﾛｯﾄ情報が見つかりません。 | **取り込み** をしてから、もう一度ロット番号を入れます。それでも出ないときは台帳にまだありません |
| 前工程実績数が 0 | 梱包課共有の仕掛にないロットです。**修正する** で手で入れます |
| 丈Nの重量が未入力です。/ 丈Nの重量が0です。 | その丈の重量を入れます |
| 丈Nの重量は整数(数字だけ)で入力してください | 小数点などが入っています。消して整数で入れ直します |
| 積み上げが埋まっていません。 | 積み条数の分だけコイルを押します |
| ロットが … に変わったので、… の画面で押した操作は使いませんでした。 | ロットが開き終わる前に打った・押したものです。開いたロットの表示を確かめて、重量などを入れ直します |
| 包装仕様NO が「(未登録)」 | 台帳の側にまだ登録がありません。担当に確かめてください |
| この画面はすでに開いています | 先に開いた画面を使います。見当たらないときだけ **この画面で使う**(§8) |
| この画面はもう使われていません | ほかの画面に移られました。新しいほうの画面を使います |
| アプリが開き直されています | **読み込み直す** を押します。途中経過は残っています |
| 赤い帯「バックエンドと通信できません」 | 裏側が止まっています。アプリを開き直してください |
| この画面は無効になりました。アプリを開き直してください | 古い画面です。開き直します |
| データベースに書き込めませんでした。ほかのプログラムが使っているかもしれません。 | 書けていません。少し待ってからもう一度押します |
| エラー番号 E… | 番号を伝えてください。統合画面の上の帯の **ログ** で中身を見られます |
| 画面が出ない | コイル梱包ツールのフォルダの `start.bat` を実行すると、原因が文字で出ます |
