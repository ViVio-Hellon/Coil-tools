# ツール文書 一覧

対象の版: コイル梱包ツール 1.2.31(梱包明細 VER 0.13.28 / ペナラベル 1.5.32 / 資材計算 0.2.28)

コイル梱包ツールは、3 つの機能(梱包明細・ペナラベル・資材計算)を 1 つの画面にまとめた統合ツールです。
このフォルダには、ツールごとに次の 3 種類の文書を置いています。

- **仕様** … 何ができるか・データの出どころと置き場所・計算や判定の決まり・設定・関連するコードの場所
- **操作説明** … 毎日の使い方を手順で。困ったときの対処
- **思想とモード** … なぜその作りにしたか(設計の考え方)と、ツールの中にあるモード・状態の説明

## 書き方の決まり

- 合言葉(パスワード)の中身は書きません。「合言葉が要る」とだけ書きます
- 確かめられなかったことは「(未確認)」と書きます
- 版を上げて中身が変わったときは、該当する文書の「対象の版」と本文を直します
