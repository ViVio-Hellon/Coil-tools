テスラ向けの出荷ラベル(小ラベル)を刷り、梱包の風袋・NW・GW・高さを計算します(梱包ペナ ラベル・風袋計算)。 統合画面の {{ m.b('ペナラベル') }} タブで使います。写真は試験用のデータです(右上の札が「CSV」になっているのは試験用の資材マスタを指定しているためです)。

1画面の見方

{{ m.fig("pena-start", "ペナラベルを開いたところ(指定サイズの画面)。") }}
  1. {{ m.n(1) }}左のタブ:{{ m.b('指定サイズ') }}(ふだんの画面) {{ m.b('風袋計算') }} {{ m.b('計算内容') }} {{ m.b('ラベル台紙') }} {{ m.b('全サイズ') }} {{ m.b('設定') }}。
  2. {{ m.n(2) }}版(v{{ versions.pena }} と、版を切った日)。画面の下の帯にも出ています。
  3. {{ m.n(3) }}接続OK:動いている印です。左の札は、資材マスタをどこから読んでいるか(SQLite・Access(ACE)・CSV)です。赤い「(古い内容)」が付いたら、資材マスタを読み直せていません。

2小ラベルを刷る(毎日の作業)

手順1 サイズを選んで重量を反映する

{{ m.fig("pena-weight", "サイズを選び、新しい検番と重量を入れて「重量反映」を押します。") }}
  1. {{ m.n(1) }}丈1と丈2をまとめてやるときは「まとめてやりたい場合チェックon(丈1・丈2 同時)」にチェックを入れます。片方だけなら外したままです。
  2. {{ m.n(2) }}サイズを選びます(0.8mm×53.5mm か 1.0mm×53.5mm。チェックを入れていれば「丈1・丈2 同時」、外していれば「丈1」か「丈2」)。選ぶと、その台紙の前の検番・重量が「現状値」に出ます。
  3. {{ m.n(3) }}新検番:英字1文字+数字1文字+英数字1文字+数字4桁の7桁(例:N6X0945・H670129)。3文字目は英字でも数字でもかまいません。小文字は大文字に直ります。7桁を超える入力は入りません(「検査番号は7桁までです」と出ます)。
  4. {{ m.n(4) }}新重量 丈1を入れます。
  5. {{ m.n(5) }}新重量 丈2を入れます(選んでいない丈の欄は薄くなって入れられません)。
  6. {{ m.n(6) }}{{ m.b('重量反映') }} を押します。「重量を反映しました」と出て、「現状値」が新しい値になります。

手順2 重量計算_DB(NW・GW・高さ)

{{ m.fig("pena-tare", "積み本数を入れて「重量計算_DB」を押すと、NW・GW・高さが出ます。") }}
  1. {{ m.n(1) }}チップボールサイズ(1000 / 950 / 820)を選びます。資材計算の仕掛パスが実績の形式なら、重量反映のときにコイル外径(内径 + 2 × 肉厚)から近いものが選ばれ、下に案内が出ます。違うときは選び直します。
  2. {{ m.n(2) }}積み本数を、丈ごとに 1梱包目・2梱包目 入れます(数字だけ打てます)。
  3. {{ m.n(3) }}{{ m.b('重量計算_DB') }} を押します。資材マスタを確かめてから計算し、「計算しました」と出ます。
  4. {{ m.n(4) }}NW・GW・高さ(mm)が出ます。計算するのは表示中の丈だけです。資材マスタに無い資材・単重が数でない資材があると「資材重量なし: …」で止まります(何も消えません)。
  5. {{ m.n(5) }}{{ m.b('小ラベル印刷') }} を押します。「…を印刷しますか？」に {{ m.b('OK') }} で、ラベルの紙面が別の窓(ブラウザ版では別のタブ)で開きます。刷ったあとも NW・GW は残ります(刷り直せます)。次のロット(違う検番)で重量反映すると消えます。
注意重量や本数を変えたら、必ずもう一度 {{ m.b('重量計算_DB') }} を押します。押さないまま刷ろうとすると「入力が変わっています。印刷を止めています。」と出て、刷れません(古い値のラベルを出さないため)。

手順3 ラベルを刷る

{{ m.fig("pena-labels-print", "小ラベルの紙面(実寸)。1台紙で16枚。上の帯の「印刷する」で刷ります。") }}
  1. {{ m.n(1) }}{{ m.b('印刷する') }} を押します。印刷の窓は何も変えずにそのまま「印刷」で大丈夫です(倍率「実際のサイズ」・余白「なし」が最初から選ばれています)。

刷り終えたら、上の帯の {{ m.b('このタブを閉じる') }} で閉じます。{{ m.b('積み高さ計算') }} は参考の高さを出すだけで、帳票には出ません。{{ m.b('クリア') }} は NW・GW・高さと本数欄を消します。

3風袋計算を見る・刷る

{{ m.fig("pena-tare-view", "左のタブの「風袋計算」。梱包ごとの資材の重さと式が見られます。") }}
  1. {{ m.n(1) }}左のタブの {{ m.b('風袋計算') }} を押します。
  2. {{ m.n(2) }}{{ m.b('印刷ビューを開く') }} を押すと、印刷用の画面が開き、すぐ印刷の窓が出ます。
{{ m.fig("pena-tare-print", "風袋計算の印刷用の画面。") }}
注意重量計算のあとで入力(重量・本数・サイズ・検番)を変えると、風袋計算の印刷ビューは「入力が変わっています。印刷を止めています。」と出て、すぐには刷りません。{{ m.b('重量計算_DB') }} を押し直してから開きます。

図で見る: 風袋計算の画面では、梱包ごとの表の下に、GW をどこから出しているかが図で出ます(印刷の紙面には出ません)。

  • 断面図(左): 梱包を横から見た模式図です。左半分は外から見た所、右半分は断面(中の重なり)で、包装仕様書(7C1175)の図に合わせています。ピン(樹脂製丸棒)4 本はハードボードの外に立て、下のパレットの穴に差します。PET バンドは胴巻き 4 本と、上下のパレットを十文字に締める縦 4 本です。高さは寸法どおりで、樹脂パレット・八角ハードボード・コイル・チップボールの積み方と、コイル積高・梱包高さ(10mm 単位で切り上げ)が出ます。資材ごとに色を分け、重さを引き出して書いています。チップボール(0.7mm)とハードボード(2.35mm)は薄すぎて見えないので、太く描いています。
  • 重さの内訳(右): GW = NW + 風袋 の帯と、風袋の 9 項目の帯です。どの資材が重いかと、それぞれの式(計算式の欄と同じ)が出ます。丸める前の値と、表示の値(四捨五入)の両方が出ます。
{{ m.fig("pena-tare-figure", "風袋計算の「図で見る」。左が断面図、右が重さの内訳。") }}

{{ m.b('計算内容') }} では梱包ごとの資材・重量・計算式を、{{ m.b('ラベル台紙') }} では14枚の台紙の一覧と、それぞれの {{ m.b('表示') }} {{ m.b('印刷') }} が見られます。戻るときは {{ m.b('指定サイズ') }}。

4全サイズ

{{ m.fig("pena-allsize", "左のタブの「全サイズ」。型番マスタのサイズを選んで、まとめてラベルを作ります。") }}
  1. {{ m.n(1) }}サイズ選択(型番マスタ)を選びます。台紙が用意されて画面が読み直されます。
  2. {{ m.n(2) }}検番を入れます。
  3. {{ m.n(3) }}コイル副番の {{ m.b('2ケタ') }}(例 1-1)か {{ m.b('3ケタ') }}(例 2-2-1)を選びます。最初はどちらも選んでいません(サイズを選ぶ・クリアのたびに戻ります)。
  4. {{ m.n(4) }}重量を入れます(指定サイズと同じく小数も入ります。3ケタのときは欄が増えます)。
  5. {{ m.n(5) }}{{ m.b('決定') }} を押すと「反映値」に結果が出ます。
  6. {{ m.n(6) }}{{ m.b('印刷') }} を押すと、印刷用の画面が開きます。
{{ m.fig("pena-allsize-print", "全サイズの印刷用の画面。") }}

5印刷の位置合わせ(プリンターごとに一度)

ラベルが台紙の枠からずれて刷られるときに、一度だけ合わせます。合わせた値はこのPCに覚え、次からずっと効きます。

{{ m.fig("pena-labels-print-note", "小ラベルの紙面の上の案内。「位置合わせ（試し刷り）」から合わせます。") }}
  1. {{ m.n(1) }}ふだんはここで {{ m.b('印刷する') }} を押すだけです。
  2. {{ m.n(2) }}ずれるときは {{ m.b('位置合わせ（試し刷り）') }} を押します。
{{ m.fig("pena-calibration", "位置合わせの画面。まず普通紙に試し刷りします。") }}
  1. {{ m.n(1) }}{{ m.b('試し刷り') }} を押して、普通紙に1枚刷ります(印刷の窓は何も変えません)。刷った紙を台紙と重ね、点線の枠がラベルの切れ目から、どっちへ何mmずれているかを定規で測ります。
  2. {{ m.n(2) }}終わったら {{ m.b('ラベル印刷へ戻る') }} で戻ります。
{{ m.fig("pena-calibration-fix", "「ずれを直す」。測った向きと量を入れて「直す」を押します。") }}
  1. {{ m.n(1) }}横のずれの向き({{ m.b('左') }}/{{ m.b('右') }})を選びます。
  2. {{ m.n(2) }}横にずれている量(mm)を入れます。
  3. {{ m.n(3) }}縦のずれの向き({{ m.b('上') }}/{{ m.b('下') }})を選びます。
  4. {{ m.n(4) }}縦にずれている量(mm)を入れます。ずれていない向きは 0 のままで構いません。
  5. {{ m.n(5) }}{{ m.b('直す') }} を押します。入れた量だけ逆に動かして刷るようになります。もう一度試し刷りして確かめます。
コツ少しだけ残ったら「少しずつ動かす」の {{ m.b('↑ 上へ') }} {{ m.b('← 左へ') }} {{ m.b('右へ →') }} {{ m.b('↓ 下へ') }} で詰めます。下の段ほどずれが大きいときは「大きさそのものが合わないとき」を開きます。元に戻すときは {{ m.b('最初（ずらさない）に戻す') }}。

6設定

{{ m.fig("pena-settings", "左のタブの「設定」。") }}
  1. {{ m.n(1) }}合言葉:フォルダやファイルの場所を変える・マスタを書き換える・配布設定を扱うときだけ要ります(印刷の位置合わせには要りません)。
  2. {{ m.n(2) }}{{ m.b('パス設定') }}:資材マスタの参照先・ラベル台紙など。変えたら {{ m.b('保存する') }}。{{ m.b('資材マスタへの接続を試す') }} で、保存せずに読めるか試せます。
  3. 資材マスタ CSV・型番マスタ CSV:{{ m.b('手本を出す') }} を押すと、欄に入れたパスへ列の見出しと例の行を出します(すでにあるファイルは上書きしません)。Excel で開いて直し、{{ m.b('この欄を保存') }}。読む順はDB が先で、DB(梱包資材マスタ。型番マスタは表「型番」)が無いときだけ CSV を読みます。欄の下に「いま読んでいる先」が出ます。
  4. {{ m.n(3) }}{{ m.b('マスタ管理') }}:資材マスタ(SQLite)の中身を見る・直す。
  5. {{ m.n(4) }}{{ m.b('配布設定') }}:この端末の設定を、ほかのPCに配る形で書き出します。
  6. {{ m.n(5) }}{{ m.b('サイズ') }}:指定サイズの画面に出すサイズを選ぶ・新しいサイズを足す(サイズを出す・足す)。

サイズを出す・足す

足し方は、左のタブの {{ m.b('ラベル台紙') }} の下にある {{ m.b('新しいサイズを足すには') }} を押しても出ます。そこの {{ m.b('設定の「サイズ」を開く') }} で、この画面へ移れます。足したサイズは、ラベル台紙の一覧に「追加」の印つきで出ます。

{{ m.fig("pena-settings-sizes", "設定の「サイズ」。") }}
  1. {{ m.n(1) }}出すサイズ:チェックを入れたサイズだけが、指定サイズの画面と全サイズの一覧に出ます(いまラインに来ないサイズの選び間違いを防ぐため)。このPCだけの設定です。足したサイズは、どのPCにも最初から出ます(外したPCだけ出ません)。
  2. {{ m.n(2) }}{{ m.b('出すサイズを保存') }}:合言葉が要ります。1つ以上は出します。
{{ m.fig("pena-settings-size-add", "「新しいサイズを足す」。写真は試験用の CSV で動かしているため「サイズを足せません」と出ています(資材マスタが SQLite なら出ません)。") }}
  1. {{ m.n(3) }}新しいサイズ:厚み(mm)・巾(mm)・型番を入れます(記号・備考は任意。備考は指定サイズの画面に赤字で出ます)。
  2. {{ m.n(4) }}{{ m.b('サイズを足す') }}:合言葉が要ります。共有の資材マスタに書くので、どのPCの指定サイズの画面にも出ます(ラベル台紙一覧に書き足す必要はありません)。
注意サイズ(厚み・巾)はあとから直せません。間違えたときは、{{ m.b('マスタ管理') }} の表「ペナラベル追加サイズ」でそのサイズの {{ m.b('この行を消す') }} を押し(合言葉が要ります。どのPCにも出なくなります)、正しいものを足し直します。型番・記号・備考はそこで直せます。資材マスタが SQLite でないとき(CSV で動いているとき)は足せません。理由が画面に出ます。全サイズの画面の一覧にも出すときは、型番マスタにも同じサイズを足してください。
{{ m.fig("pena-settings-storage", "「設定の保存先（このPC／複数のPCで共有）」。") }}

このPCに保存のもの(この端末の設定・印刷位置の補正・作業の状態)はこのPCだけで使います。全ラインで共有のもの(資材マスタ)を変えると、ほかのラインにも効きます。

資材マスタは、SQLite → Access(ACE)→ 同梱の CSV の順に読める物を使います。どれを読んだかは右上の札に出ます。

7版を確かめる

ペナラベルの版は、画面の左上の「v{{ versions.pena }}」と、画面の下の帯に出ています。下の帯の {{ m.b('診断') }} を押すと、版・版を切った日・資材マスタをどこから読んだかなどがまとめて出ます。問い合わせのときに伝えてください。

下の帯の {{ m.b('計算・印刷の記録') }} では、計算と印刷のたびにどの取得元(SQLite / Access / CSV / 古い内容)の、いつ時点の資材重量だったかが新しい順に見られます(この PC の分)。どの版で・どの PC(ライン)で、も出ます。印刷画面の行は印刷の画面を開いた記録で、刷った証拠にはなりません(刷ったか・やめたかはブラウザから分かりません)。止めた印刷は、入力が変わったまま印刷を止めた記録です。下には資材マスタの編集履歴(いつ・何を何から何に。このツールから直したときは誰が、も)が出ます。資材マスタ(SQLite)が直されると、資材マスタ自身が自動で書きます(ツールの外で直しても残ります)。記録は月ごとのファイルにも残り、設定の「計算・印刷の記録の保存先フォルダー」を入れるとそこにも PC ごとに書きます(この PC への保存はそのまま)。ファイルはCSV で、Excel でそのまま開けます(設定の「記録ファイルの形式」で JSONL・両方にもできます)。見るときは写しを開くか、読み取り専用で開いてください。設定の「ライン名（このPC）」を入れると、記録にライン名も残ります。資材重量の変化は、計算のときに読んだ資材重量が前と変わっていた記録です(ツールの外で直した分も分かります)。

テストモード実機で試験するときは、設定の「テストモード（実機の試験中）」を入れます(合言葉が要ります)。記録と資材マスタの編集履歴に「テストモード」と残り、画面の右上に赤い「テストモード」の札が出ます。試験が終わったら必ず切ってください。

8困ったとき

出たもの・起きたことすること
検査NOが7桁入力されていない もしくは …桁目に…が入力されています英字1文字+数字1文字+英数字1文字+数字4桁で入れ直します(例:N6X0945)。「W111E11」のように数字の所に英字があっても出ます。
検査NOは7桁です(N桁入力されています)/検査番号は7桁までです7桁で入れ直します。
重量入力がありません 丈1(丈2)選んだ丈の重量を入れます。
サイズが選択されていません/コイルサイズが選択されていませんサイズを選んでから押します。
本数が入力されていません積み本数を入れてから {{ m.b('重量計算_DB') }}。
入力が変わっています。印刷を止めています。指定サイズの画面で {{ m.b('重量計算_DB') }} を押し直してから刷ります。
資材重量なし/資材重量なし: 資材マスタに無い資材、または単重・係数が数でない資材があるので、計算を止めました資材マスタを読めていないか、マスタに無い資材・単重が数でない資材があります。読めないときは、何が読めなかったか・何を確かめればよいかが出ます(閉じるまで消えません)。設定の {{ m.b('資材マスタへの接続を試す') }} か、下の帯の {{ m.b('診断') }} を見て、担当に伝えます。
この画面は開けません/この画面は使用中ではなくなりましたペナラベルは1つの画面でしか使えません。先に開いた画面を使います。見当たらないときだけ {{ m.b('この画面で使う') }}。
接続なし — 再読込してください画面を読み込み直します(F5)。直らなければアプリを開き直します。
エラー番号 E…番号を伝えてください。統合画面の {{ m.b('ログ') }} で中身を見られます。
